### **Experimental lockfile format v13 arrives** (e3c8d03)
pnpm can now write `pnpm-lock.yaml` in the new `lockfile.format: v13` layout, a JSON-like format with tabs, trailing commas, and a flatter `packages` structure. It also reads the boot document from v13 lockfiles so projects can still switch to the pinned pnpm version they declare.

### **Global virtual store builds no longer block on locks** (dce692e)
Builds for shared virtual-store packages now happen in private directories and are moved into place only after they finish, so concurrent installs no longer wait on each other or link half-built packages. The refactor also changes how failed builds and prune handling work, removing the old lock/marker flow across pnpm 11 and 12.

### **Offline deploy can reuse source lockfile resolutions** (a019200)
`pnpm deploy --offline --trust-lockfile` now reuses source lockfile pins from a populated store even when registry metadata is unavailable. That extends to per-project lockfiles, legacy deploy mode, and npm aliases.

### **updateConfig filters now resolve from the workspace root** (48b76c9)
Relative `filter` and `filterProd` selectors injected by `updateConfig` hooks are rebased so they behave consistently from the workspace root, even when `--dir` or a subdirectory invocation is involved. This fixes hook-driven project selection that previously missed targets.

### **Store prune and clone cache behavior tightened** (cc6fef4)
Local clone-cache materializations are now separated from the global virtual store, and `pnpm store prune` clears that cache instead of letting unused clones accumulate. Prune also stops on unreadable links to avoid deleting packages after an incomplete scan.

### **Config deps preserve registry serverType** (0d64761)
Config dependency installs now carry through the registry `serverType` when they serialize tarball URLs and when they reconstruct them at install time. That fixes mismatches for registries that depend on the URL form.

### Other misc changes
- Re-derive `requiresBuild` for legacy git store rows in pnpm 11 (297701d)
- Workspace state now records `runtimeOnFail` so repeat installs notice runtime policy changes (9ada92d)
- Catalog `workspace:` links are retained in lockfiles when `excludeLinksFromLockfile` is enabled (48633b3)
- Windows cmd shims switch code pages without clearing the terminal (c0cf748)
- `get-pnpm` respects hidden-directory exclusions when choosing a pin (b2b2d1f)
- UUID-named lockfile staging files are now pruned by fs-packlist (61ca598)
- Dependency bumps, release-note curation, tests, docs, and small refactors (several commits)
