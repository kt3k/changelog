### **API and background tasks were split into separate crates** (e23fc70)
The monorepo now separates shared code, tasks, and the HTTP API into distinct crates, with `shared/` housing common database/storage/client code and `tasks/` owning publishing, npm tarballs, email, and periodic jobs. This is a major internal restructure that should make the codebase easier to build and deploy, while preserving the existing `/tasks` routes and Cloud Tasks/Cloud Scheduler flow.

### **Registry API now runs as a Cloudflare Worker** (93d7ec4)
The API is now built for `wasm32-unknown-emscripten` and deployed as a Cloudflare Worker behind service bindings, replacing Cloud Run for API traffic across environments while background jobs stay on the Cloud Run tasks service. The change also adds worker-specific build/lint/test plumbing and artifact handoff in CI, so the new deployment path is enforced end to end.

### Other misc changes
- CI workflow updates around the new crate layout and workspace-wide Cargo commands
- License data path moved from `api/` to `shared/`
- License/config ignore list updates and related repo housekeeping
