### **Add `--no-runtime` to skip runtime installs** (e1e29c1)
Pacquet can now skip installing `devEngines.runtime` entries while leaving the lockfile untouched, so frozen-lockfile checks still pass. This is useful for CI setups where the runtime is provisioned separately and only the fetch/bin-linking step should be suppressed.

### **Persist `node_modules/.modules.yaml` after install** (e50f912)
After a successful install, pacquet now writes the modules manifest with the resolved layout, linker, included dependency groups, store/virtual-store paths, registry, and package-manager identity. This mirrors upstream pnpm behavior and gives later installs a durable record for detecting layout changes and pruning correctly.

### **Workspace config load failures now surface as errors** (0df762b)
Loading `pnpm-workspace.yaml` is no longer best-effort when the file exists but is unreadable or malformed: those failures now bubble up instead of being ignored. That makes CLI behavior match pnpm more closely and prevents commands like store operations from silently proceeding with a bad workspace config.
