### **Router stack moved to axum and hyper 1** (8c0d191)
The API routing layer was refactored off routerify onto axum 0.8 with hyper 1. Route declarations switched to axum’s `{param}` syntax, and request helpers now come from a local `RequestExt` backed by extensions. This is a major infrastructure change that modernizes the server stack and removes the old routerify dependency.

### **Broader dependency upgrade across docs, highlighting, and storage** (a67a979)
The day also brings a substantial dependency refresh: reqwest gained streaming support, S3 code moved from `rust-s3` to `rusty-s3`, and the docs/highlighting stack was bumped to newer `deno_doc`, `comrak`, and `tree-sitter-highlight` versions. The source-view highlighter now writes into a `String`, and the lockfile/toolchain updates reflect the new baseline required by these upgrades.

### Other misc changes
- Added `From<std::fmt::Error>` conversion for API errors.
- Minor internal adjustments in package/docs/error handling to accommodate the dependency changes.
