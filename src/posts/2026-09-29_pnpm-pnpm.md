### **Install/deploy correctness and frozen-lockfile behavior improve**
Multiple fixes land around install gating, deploy, and frozen installs. pnpm now preserves the dedupe baseline across frozen refreshes, keeps repeat installs fast for injected workspace deps, and fixes deploy for injected packages whose peers are also dev dependencies. It also rejects stale `Cargo.lock` files in frozen mode and respects `pmOnFail` when preparing git-hosted deps. (5eaad67, 0ef7d99, 3c855aa, 51f45cd, 9f41ad6)

### **Resolver gets faster and smarter**
pnpm ships several resolver-level improvements: shared package IDs reduce allocation and string churn in large workspaces, concurrent first misses are coalesced per wanted key, and registry version-picking is faster by a wide margin. The metadata filter also now chooses a better fallback for `latest` when minimum release age hides the current stable release. (a949da4, 4148fdb, 3aa1383, a44243f)

### **CLI/config and lifecycle edge cases are hardened**
The CLI now refuses machine-level settings in project manifests, ignores `globalShims` there too, correctly parses clustered `-g`, and defaults `childConcurrency` to 5. Lifecycle handling also fixes zombie-process waiting, PATH handling on non-Windows, and shim helper lookup when the default system path is incomplete. (3a6bfa1, 8703de2, f593ccd, a8e9358, b8d53ce, 2b511eb, a04402f)

### **Store, network, and platform fixes**
Store locks now prefer `$XDG_RUNTIME_DIR` when available, `pnpm store prune` cleans expired dlx cache entries first, and network client setup keeps `NODE_EXTRA_CA_CERTS` additive even on systems without CA bundles. A release fix also prevents ppc64le startup crashes by routing the linker through bundled LLD. (ec65716, bb7236f, ffe2648, 09bbe5b)

### **Docs and test infrastructure move forward**
Documentation was moved and consolidated alongside the codebase, sidebar structure was flattened, and a new WebContainer-based ecosystem E2E harness was added. pnpm also gained coverage for shell precedence, a validate-allow-builds reader check, and a few targeted regressions. (07839df, 417ab35, 3675fbe, 620c8ab, 05b47a4, 8b906af)
