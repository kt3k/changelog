### New iterator API
**Iterator.prototype.join** now joins iterator values with an optional separator, defaulting to `,`, while defining abrupt-completion handling and skipping `undefined`/`null` values.

### Number and time terminology tightened
**Finite Number wording is normalized** across core Number definitions and algorithms, replacing ambiguous uses of “finite” and fixing autolinks and related preconditions.
**Finite time value** is now an explicit term in the time-values section, giving later clauses a precise reference without changing behavior.
**Loose equality BigInt/Number checks** were clarified by moving the finite-number requirement directly into the relevant branch.

### Other misc changes
**Editorial consistency passes** touched Number.prototype math/formatting algorithms, Number.isFinite, Number.MAX_VALUE, Number::remainder assertions, and a few comparison/power/remainder clauses.
