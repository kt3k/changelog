**pacquet gets a full `bugs` command implementation** (ddbb489)
Ported `pnpm bugs` into pacquet, including manifest-based lookup and registry lookup by package name. The new command also normalizes repository URLs across GitHub/GitLab/Bitbucket shorthand, hosted git URLs, and self-hosted git servers, with broad unit coverage for the URL-derivation paths.

**Lifecycle streaming no longer crashes on infinite width** (397f978)
Fixed reporter output so streamed lifecycle logs bypass `cli-truncate` when the width is `Infinity`. This avoids a runtime crash in lifecycle script streaming while preserving existing truncation behavior elsewhere.
