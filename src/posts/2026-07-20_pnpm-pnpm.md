### **`pnpm list` / `pnpm why` reach TypeScript parity** (d50b4dd)
Pacquet rebuilt list/why around a shared dependency-tree module, making the commands feature-complete and byte-for-byte aligned with the TypeScript CLI. This adds deduped/circular subtree handling, peer and skipped annotations, absolute paths, reconstructed tarball URLs, version-range search, and richer JSON/parseable output.

### **Install surface parity gaps are closed** (d62795a)
This adds several user-facing install/config behaviors: `--force` for install/add, `enableModulesDir: false`, `extendNodePath`, and `sharedWorkspaceLockfile: false`. It also wires `--force` through deploy/global paths so forced installs relink already-materialized packages and keep optional deps that would otherwise be skipped.

### **Install-state recovery and PnP materialization are fixed** (b8a4d38)
Pacquet now recovers more gracefully from broken private lockfiles and expired module-cache state, instead of getting stuck on stale install data. The same work also lands PnP loader materialization and preserves the expected symlink/bin behavior around PnP and frozen installs.

### **Workspace lifecycle ordering and bin linking now match pnpm** (0cb4a18)
Workspace install/add/remove/update now preserve topological group ordering and respect child concurrency when running lifecycle scripts. The day also tightens bin relinking behavior for hoisted layouts and direct-dependency precedence, which should remove a class of ordering-dependent workspace bugs.

### **Git dependency handling is more complete** (45f06ce)
Git dependencies now handle alias-less adds, preserve locked Git commits across unrelated manifest changes, and report clearer version information in install logs. The supporting test coverage expands across git-hosted installs, prepares, peers, and lockfile reuse.

### **Tarball cache hang fixed** (b92edcb)
A rare lost-wakeup race in the tarball in-memory cache could leave installs or adds waiting forever when concurrent fetches hit the same URL. The fix reorders notification registration so a waiter can’t miss the completion signal.

### **Resolution and verification parity improvements** (ea1d6ef)
Engine and installability checks now match npm-semver prerelease semantics more closely, including `includePrerelease` behavior for fully specified ranges. The patch also improves catalog cleanup and peer-resolution/installability coverage.

### **Global virtual store and fetch behavior improved** (b5bacb5)
Fetch now populates the virtual store without linking importer dependencies into projects, matching the expected virtual-store-only behavior. Global virtual-store recovery also gets more robust when interrupted builds leave behind marker state.
