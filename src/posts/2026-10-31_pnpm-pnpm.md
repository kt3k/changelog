### **Runtime installs no longer loop on a global pnpmfile** (5b5de10)
Installing a pinned Node runtime through the shim now ignores `globalPnpmfile`, preventing the hook worker from re-entering the same `node` shim and hanging on lock contention. This fixes a nasty deadlock/orphan-worker failure mode for `node` and `pnpm install` when the runtime hasn't been downloaded yet.

### **`pnpm link` now rejects invalid package names up front** (6048369)
`pnpm link` now validates the target package name before writing anything to `package.json` or `pnpm-workspace.yaml`. That avoids poisoning workspace overrides with an invalid name that would break all later installs until manually repaired.

### **Patch vulnerable minimatch and glob releases** (b003905)
pnpm adds local patches for `minimatch` and two `glob` lines to address the 2026-10-30 advisories. The patches align the vendored packages with the security fixes without relying on unsafe overrides.
