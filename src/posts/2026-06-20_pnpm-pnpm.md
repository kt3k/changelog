### **pnpr now blocks vulnerable versions from a local OSV index** (0d24a60)
pnpr can now load an OSV npm dump from disk at startup and use that in-memory index during resolution, failing fast if the database is missing or invalid. It also normalizes matching and evaluation so package versions can be rejected deterministically before requests are served.

### **`pnpm sbom` can now exclude peer dependencies** (6c35a43)
A new `--exclude-peers` flag omits peer dependencies and any subtree reachable only through them from generated SBOMs, which is important for published libraries where peers are consumer-provided. The implementation reads peer names from manifests rather than the lockfile so peers resolved via auto-install are filtered correctly.

### **`pnpm audit` no longer blows up on cyclic graphs** (d3f68e2)
Audit path reachability is now computed with Tarjan SCCs, fixing a performance regression that made cyclic lockfiles repeatedly recompute the same data. The walk is also iterative now, avoiding call-stack overflows on deep dependency chains.

### **Resolver peer reuse is now deterministic** (1cbb5f2)
The shared-children peer reuse logic no longer depends on whether the owner’s resolution had settled at claim time, which could vary under concurrency. That removes run-to-run lockfile churn and intermittent `dedupe --check` failures caused by optional transitive peers appearing or disappearing.

### **Hoist symlinks get replaced when GVS is toggled on** (1488db1)
When a project switches from a non-global virtual store to global virtual store mode, stale hoisted symlinks under `node_modules/.pnpm/node_modules` are now detected and replaced instead of being silently preserved. This fixes leftover links pointing at the old virtual-store location.

### **Shared-runtime cleanup and release/CI fixes** (fc2f339, a84d2a1, 9d7627c, 6379dc1, 8c3a372, 6545793, 05b95ab, 12baab4, 258b112, f6dde62)
- TypeScript pnpm CLI moved under `pnpm11/`, with follow-up wiring fixes for release artifacts, CI paths, config reads, and code ownership.
- Tarball URL resolution was consolidated into a new internal package and the canonicalization logic was tightened.
- `validateModules`-style cleanup now purges `node_modules` when layout settings change.
- Network fetch now rejects non-retryable errors properly instead of hanging.
- Misc CI/workflow and config hygiene changes, including fork-safe ecosystem-e2e behavior.
