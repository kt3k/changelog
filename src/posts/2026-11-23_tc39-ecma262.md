### **Async built-ins now resolve with their return value** (a91dca2)
The spec now explicitly unwraps a normal completion from async built-in function evaluation and returns `ReturnCompletion(_result_.[[Value]])` before continuing. This fixes cases where async built-ins could incorrectly resolve to `undefined`, aligning them with the intended behavior.
