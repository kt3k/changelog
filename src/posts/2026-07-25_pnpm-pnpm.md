### **Add pre-command checks for pinned package managers and runtimes** (0cb0127)
pnpm now validates the project’s `packageManager`, `devEngines.packageManager`, and runtime pins before commands run, instead of silently ignoring mismatches. It also honors `pmOnFail` / `runtimeOnFail` and keeps the version-switch path separate from runtime validation, which closes a major gap in CLI parity.

### **Support `saveWorkspaceProtocol` in the Rust engine** (a82b30e)
`pnpm add <pkg>@workspace:...` now rewrites workspace dependencies the same way pnpm does, including the default `rolling` behavior and the `true`/`false` variants. This is a public-facing install behavior change that affects how workspace dependencies are recorded in manifests.

### **Teach update about `--workspace` and per-dependency depth** (0ab9a51)
pnpm update now supports workspace-linked updates and applies `--depth` per dependency instead of treating it as a simple on/off threshold. That makes update behavior much closer to pnpm’s and fixes cases where workspace packages or deep dependencies were previously handled incorrectly.

### **Fix peer-hoisting to respect overrides and the workspace root** (71a4934, 68adca9, 3f97c24, d17710c)
Several commits tighten peer resolution so hoisted peers use the workspace root’s dependencies, obey overrides, and don’t leak optional peer-only aliases into importers that opted out of auto-installing peers. These are substantive correctness fixes for workspace installs and should eliminate a class of duplicate or wrongly-linked peer dependency issues.

### **Resolve missing versions, package errors, and tarballs with pnpm’s codes** (063094d, 55d9514)
Resolver errors now surface pnpm’s expected diagnostics, including the right codes and richer hints for missing versions/packages. The tarball path also regains support for git-hosted archives without `integrity`, while still rejecting unpinned remote tarballs.

### **Fix lockfile and manifest compatibility issues** (2d6c35e, e2b4556, 352125d, b4032e8, 069bc0f)
The day includes several compatibility fixes: BOM-prefixed manifests now parse correctly, pnpm 10 lockfile shapes for `patchedDependencies` and scalar `libc` metadata are accepted, and `.npmrc` credential scoping is more precise. These changes prevent old or editor-touched projects from failing outright during install.

### **Other misc changes**
- CLI parsing fixes: `--workspace-root`/`-w`, `approve-builds -g`, `run`/script shortcut forwarding, argv escape handling, and `pnpm list` package-manager recording
- Workspace/update UX and warning improvements, including legacy `package.json#pnpm` setting warnings and interactive update labels
- Bug fixes in fs locking, optional dependency handling, licenses, workspace globbing, test stability, and temp-dir cleanup
- Dependency bumps, CI/test fixture updates, and other low-impact maintenance
