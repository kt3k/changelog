### **Security: block config-lockfile path traversal and trusted bootstrap resolution** (bee4bf4, 6e218db)
pnpm now validates config dependency names and exact versions before they are turned into filesystem paths, closing a path-traversal risk from malicious env lockfiles. Pacquet also now resolves package-manager auto-switch bootstrapping through trusted registries/config only, so repository-controlled registry settings can’t redirect pnpm/@pnpm/exe downloads.

### **Per-package SBOM generation with `--out` and `--split`** (1495cb0)
SBOM generation can now target individual workspace packages, writing one file per package via `--out` or streaming split NDJSON via `--split`. The implementation also uses the selected package’s own metadata when appropriate and includes workspace inter-dependencies, making SBOM output much more useful for monorepos.

### **Warm installs stop relinking unchanged child deps** (1c05876)
Relinking during warm installs is narrowed to only the changed child edges, rather than broadly relinking existing packages. It also removes stale child links when dependencies disappear, fixing a class of stale-link bugs after updates.

### **macOS imports now strip Gatekeeper quarantine from native binaries** (1b02b47)
On macOS, pnpm now removes `com.apple.quarantine` from imported native binaries after store-backed installs. This prevents Gatekeeper from blocking verified `.node`, `.dylib`, and `.so` files that picked up quarantine metadata upstream.

### **Recursive `pnpm version` now honors the CLI’s selected workspace set** (9d0a300)
Recursive version bumps now use the already-computed `selectedProjectsGraph` instead of re-deriving selection with incomplete options. That keeps `pnpm version --recursive` aligned with the user’s actual `--filter`/workspace selection.

### **SBOM scope and output enhancements, plus installer correctness fixes** (1495cb0, 3b54d79, 5c12968, 96bdd57, 3f0fb21, 9d79ba1, ff9a1cf)
Several smaller but user-facing fixes landed around update, progress rendering, workspace dependency deduping, and pnpr proxy behavior. Notably, pnpr gained per-uplink Verdaccio tuning knobs like `maxage`, `timeout`, `max_fails`, `fail_timeout`, and `cache`, and `pnpm update --help` now documents `--no-save`.
