**pnpr can now serve browser registry UIs** (879347f)
The registry server now supports exact-origin CORS allowlists for separately hosted browser UIs, plus pagination, maintainer discovery, authenticated publisher records, organization package maps, and optional upstream search/discovery. It also tightens routing and access checks so local packages are filtered correctly before counts/results are returned.

**Lockfile serialization gets a parallel fast path** (8c5f3a8)
Large workspace lockfiles now lower big map sections in parallel before YAML emission, while preserving byte-identical output. This targets the expensive importers/packages/snapshots serialization path and should cut write time on huge repos.

**Dependency resolution avoids repeated hashing in large workspaces** (cdd1131)
The resolver now caches wanted-key hashes and parallelizes importer drift checks. That reduces per-edge overhead during warm updates, which matters most in large multi-project workspaces.

**Stage approval now derives dependency order from tarballs** (5e184be)
`pnpm stage approve` now downloads and inspects every selected tarball up front, then orders approvals from the published manifests instead of the local workspace. That avoids incorrect dependency ordering when the maintainer checkout differs from the staged artifacts and makes batch approval more robust.

**pacquet and pnpm can run even when the native bin never installs** (779b40e, 1e57a51)
The placeholder `pnpm` bin was turned into a runnable shell wrapper, and install/CLI argument handling was widened so boolean settings like `--unsafe-perm` are accepted across commands. Together these fixes unblock environments that skip build scripts and prevent installs from failing on bare boolean flags.

**Store verification stops deleting blobs on transient failures** (3ccf87c)
Integrity checks now leave CAS blobs in place when verification fails, only scrubbing a directory squatting at the blob path. This avoids corrupting a shared store during concurrent installs and prevents spurious ENOENT-style import failures.

### Other misc changes
- Docs updated to make pnpm v12 the feature-development target; pnpm v11 is now maintenance-only.
- Release/process updates for staged package approval and cross-build retries.
- Several dependency bumps and release/changelog refreshes.
- Minor CI/workflow and internal config tweaks.
