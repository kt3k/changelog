**Add missing `Symbol.dispose` and `Symbol.asyncDispose` properties** (60c663a)
The spec now explicitly defines both well-known symbol properties on `Symbol`, including their initial values and non-writable, non-enumerable, non-configurable attributes. This closes a gap in the normative text for the disposal symbols.

### Other misc changes
- Updated GitHub Actions workflows to `actions/checkout@v7` across build, deploy, formatting, typecheck, IPR, biblio publish, and spellcheck jobs.
- Hardened `pr-preview` checkout with `allow-unsafe-pr-checkout: true` for trusted preview PRs.
