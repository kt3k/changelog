### **URL-scoped registry auth now works from env vars (615c669)**
pnpm can now read registry/auth settings from `npm_config_//…` and `pnpm_config_//…` environment variables, giving a file-free way to supply host-scoped credentials like auth tokens. The config reader was updated to merge these env-scoped values at the right priority, and the Rust config layer got matching auth parsing and tests.

### **Default network concurrency was raised for faster installs (84bb4b1)**
pnpm now defaults to a much higher network concurrency, from `min(64, max(cpuCores * 3, 16))` to `min(96, max(cpuCores * 3, 64))`. That should better saturate fast registries, especially on low-core CI runners that were previously capped too low.

### **Install and resolver paths were optimized for warm metadata and symlink churn (cb18695, 657d322)**
Two separate perf tracks landed: one reduces metadata hydration and adds a sharded/indexed registry cache, and the other schedules tarball downloads by estimated pipeline work instead of FIFO. Together they target warm-resolve latency, reduce unnecessary work in the package picker, and improve overall throughput under download contention.

### **Lockfile verification now reports cached passes (f11b4fc)**
When lockfile verification reuses a cached passing verdict, pnpm now prints a visible “passes supply-chain policies” message instead of staying silent. The reporter also includes how long ago the verdict was verified when that timestamp is available, which makes the security gate feel explicit even when it short-circuits.

### **Project .npmrc env warnings are clearer and safer (bc9ed78)**
Warnings for ignored environment-variable expansion in project `.npmrc` files now explain the security risk and point users to trusted places to move the setting. The new messaging also avoids suggesting runnable `pnpm config set` snippets when the key could be shell-unsafe, preventing copy-paste injection hazards.

### **Release 11.6.0 refreshed generated metadata (53b1054)**
The release commit updated the versioned package manager metadata and changelog artifacts across the repo to match pnpm 11.6.0.
