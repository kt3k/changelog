### **Pluggable SQL auth backends for pnpr** (bd5390e)
pnpr can now be built with libsql, PostgreSQL, or MySQL auth backends instead of being tied to one database driver. That broadens deployment options and keeps the existing user/token trait-object abstraction intact, while adding backend selection and validation in config.

### **pacquet ports create, restart/stop, and cat-file** (6367954, bdc1b07, 247201e)
The Rust CLI picked up several core pnpm commands: `create` now maps starter-kit names and delegates through `dlx`, `restart`/`stop` mirror script lifecycle behavior, and `cat-file` reads CAFS blobs from integrity hashes. These are substantial parity wins that make the experimental Rust implementation more usable for real workflows.

### **Manifest rewriting is fixed for failed optional updates** (322f88f)
`updateProjectManifest` now carries the originating wanted dependency through resolution, so save/update logic targets the exact request rather than reconstructing pairings by index or alias. This prevents failed optional installs from mutating unrelated dependency specs and fixes a class of manifest corruption bugs.

### **Audit fix now merges minimum release-age excludes** (25a829e)
`pnpm audit --fix` now writes a single combined `minimumReleaseAgeExclude` entry per package and merges existing per-version entries into that canonical form. That aligns output with documented config format and avoids duplicate policy entries in workspace manifests.

### **Hosted git adds are normalized before save** (b4fdfe9)
`pacquet add` now saves hosted git dependencies in shortcut form (`github:owner/repo#sha`, etc.) instead of verbatim URLs or shorthands. This matches pnpm’s normalized specifier behavior and preserves auth-bearing URLs when shortcutting would drop credentials.

### Other misc changes
- Reduced Qodo inline-comment noise on iterative PRs.
- Bumped `insta` from 1.47.2 to 1.48.0.
