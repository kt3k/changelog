### **Iterator.prototype gains chunks and windows** (4a0d3f8)
The spec adds two new iterator helper methods: `Iterator.prototype.chunks(_chunkSize_)` and `Iterator.prototype.windows(_windowSize_, _undersized_)`. Both validate their size arguments, close iterators on abrupt completion, and yield arrays representing fixed-size groups or sliding windows.

### **Indexed property joining is centralized for Array and TypedArray methods** (da42764, 2fb432e, 9c15fe3, c0d912a)
`Array.prototype.join`, `Array.prototype.toLocaleString`, and `%TypedArray%.prototype.toLocaleString` are now routed through a shared `JoinIndexedProperties` abstract operation. The refactor also generalizes the helper for ECMA-402 use, adds support for method arguments, and splits out `LocalizedListSeparator()` for locale-sensitive separators.

### **CreateListFromArrayLike default enum value renamed** (8e7c40c)
The default `validElementTypes` value changes from `~all~` to `~any~`. This is an editorial terminology cleanup, but it touches a low-level abstract operation name used throughout the spec.

- Spell-check script switched to UTF-8 dictionary output (ac5f876)
