### **Prefer hardlinks before clone on Linux for auto installs** (daecf87)
`packageImportMethod: auto` now uses the cheaper hardlink tier first on Linux instead of trying reflinks/clones first. That cuts warm-store `node_modules` materialization time notably on btrfs, while leaving ext4 behavior unchanged and preserving clone-first behavior on macOS.

### **Don’t let partial publish-time metadata block mature versions** (e500715)
When `minimumReleaseAge` is enabled, pnpm now detects abbreviated packuments whose `time` map is incomplete and re-fetches full registry metadata before filtering. This prevents older, valid releases from being treated as “not mature” and avoids falling back to the lowest matching version.

### **Keep packed workspace dependency order stable** (0fff84c)
Packed workspace manifests now preserve the original dependency declaration order instead of serializing in read-completion order. That makes `pnpm pack` output deterministic across runs, which matters because the manifest feeds the tarball hash.

### Other misc changes
- Dependency/catalog cleanup after removing `p-map-values` from the workspace.
- Tests and docs updated around pack manifests, publish-time handling, and import-method reporting.
