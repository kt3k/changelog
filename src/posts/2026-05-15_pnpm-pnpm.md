### **Self-update now honors minimum release age** (b6e2c8c)
`pnpm self-update` now applies `minimumReleaseAge` and `minimumReleaseAgeExclude` when choosing which pnpm version to install, instead of blindly following the latest tag. The same change also centralizes version-policy derivation and normalizes invalid exclude-pattern errors across `self-update`, `dlx`, `outdated`, and resolver paths.

### **Unset `${VAR}` placeholders no longer leak into publish auth** (a62f959)
`.npmrc` auth values with unresolved environment placeholders are now treated as empty rather than passed through verbatim. This fixes OIDC trusted publishing flows where `actions/setup-node` leaves `_authToken=${NODE_AUTH_TOKEN}` in place, which previously could be sent to the registry as a literal bearer token and cause publish failures.

### **Install now writes workspace state after pacquet installs** (4ababc0)
The package manager now persists `.pnpm-workspace-state-v1.json` at the end of install, matching pnpm’s own install flow. That avoids pacquet-built `node_modules` trees tripping `verifyDepsBeforeRun` and forcing unnecessary reinstalls because the workspace state file is missing.

### **Lockfile parsing works with CRLF line endings** (6e93f35)
The streamed YAML lockfile reader now normalizes Windows CRLF line endings before looking for document separators. This fixes broken-lockfile and outdated-lockfile errors when config dependency lockfiles are checked out on Windows.

### **Windows 8.3 temp paths are accepted in IPC tests** (ae703b1)
The IPC test helper now allows `~` in shell-argument paths, which unblocks Windows runners that expose `os.tmpdir()` as an 8.3 short-name path. That prevents shell-arg validation from failing on common GitHub Actions Windows environments.
