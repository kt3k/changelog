### **Deploy linked workspaces with singleton peers** (00f3887)
`pnpm deploy` no longer hard-requires `injectWorkspacePackages`; linked workspace deps are rewritten into the deploy lockfile and their peers are bound against the deployed graph. If a peer can resolve to multiple versions, deploy now fails with a specific `ERR_PNPM_DEPLOY_AMBIGUOUS_PEER` that names the package and competing versions.

### **Authenticate Node.js mirror downloads** (3af5322)
Node runtime downloads now reuse URL-scoped npm registry auth for mirror indexes, SHASUMS, signatures, and archives. That closes a real gap for private mirrors and keeps checksum metadata from leaking across credential contexts.

### **Workspace discovery gets concurrent and faster** (8873e62)
Workspace project discovery now fans out include-pattern expansion and manifest reads across rayon instead of doing them serially. This is a meaningful install/scoping speedup for very large repos.

### **Run regexp-selected scripts concurrently** (38b9d0d)
Regexp-matched scripts now execute under workspace concurrency instead of one-by-one, matching the TypeScript CLI behavior. The change also preserves interrupt handling and cancels remaining scripts when one fails.

### **Fix peer resolution for workspace catalogs** (6da427c)
Workspace package peers are now resolved through the effective workspace catalogs before pnpm decides whether they are unmet. This fixes false peer errors for linked and injected workspace packages using `catalog:` ranges.

### **Repair lockfile snapshots from a single view** (d9ba3f3)
`pnpm install --fix-lockfile` now derives its repair and filtered-merge views from one lockfile snapshot. That prevents repairs from mixing data from different generations and eliminates a class of inconsistent lockfile fixes.

### **Preserve UTF-8 in env substitution** (89265d4)
Environment placeholder replacement now keeps untouched source spans as UTF-8 strings instead of re-encoding them. This fixes non-ASCII config paths and values being mangled during substitution.

### **Other misc changes**
- Docker/release workflow hardening and release-binary verification
- Pacquet release bumps and dependency updates
- Audit CLI fixes for bare `--fix`, newline output, and override handling
- Peer-resolution and workspace edge-case bug fixes
- Windows/WSL shim, job-control, and staging-retry fixes
- Additional perf work in resolver, graph hashing, and peer reporting
- Test-only coverage updates across install, deploy, peers, and runtime flows
