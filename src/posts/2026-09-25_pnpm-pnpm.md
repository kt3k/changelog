### **Install correctness gets multiple high-impact fixes**
Several install paths were hardened: optional dependencies now install correctly under `--dev`, failed optional builds are removed instead of left broken, strict build policy is enforced on repeat-installs, and stale patch hashes in lockfiles are now repaired or rejected (8954744, 69b467c, 11897de, ec62861). These changes close correctness gaps that could silently leave `node_modules` inconsistent or outdated.

### **Security and network behavior tightened in pnpr and fetching**
`pnpr` now refuses connections to loopback/private/internal addresses unless explicitly allowed, closing off accidental access to metadata and other internal endpoints (e289a12). Separately, tarball and metadata fetching now fail fast on untrusted TLS certificates instead of retrying pointlessly, and transient metadata fetches get a more robust retry path (72baf83, be5f244).

### **Windows, shims, and runtime switching were fixed across the board**
Windows command shims now escape `%`, resolve nested targets correctly, and handle `cmd.exe`/Cygwin/relative-path cases that previously broke bin launches (682557f, 43e86d0, 0b11ab5, e8cfd55). pnpm setup/self-update/env handling was also corrected so installed Node versions and global shims behave consistently across platforms (a06b48c, 3478d6f, a30210e).

### **Deploy, workspace, and injected dependency handling improved**
Legacy deploy now preserves package-manager pins, nested linked dependencies, and runtime-related lockfile edges so deployed projects stay runnable and reproducible (25fb176, 073425b, d136989, 92b3552). Injected workspace dependencies were also made more reliable when their publish directory is produced by `prepare`, when they need refreshes after rebuilds, and when dedicated lockfiles are used (deca729, 0e9bbb8, 47b9866).

### **Peer resolution and package management got important fixes**
Peer handling was refined so auto-installed peers, optional peer providers, and nested locked peer aliases resolve and dedupe correctly across updates and installs (5a8fffb, 4154b96, 638504a, d7b9884, 7c207af). Add/update behavior also became more predictable for exact versions, catalog overrides, and source changes (2af93ac, 1f81ee1, b0de877, d5532fa).

### Other misc changes
- Docs updates for resolver, pruning, building, and release notes.
- CI/workflow tweaks and dependency bumps.
- Smaller CLI fixes for `root`, `list`, `sbom`, `doctor`, `pipeline`, `login`, and `config`.
