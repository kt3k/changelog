### **pnpr moves metadata to libSQL and speeds up writes** (79870bb, 326c5e1, e092130, e014344, 7a96108)
pnpr now supports shared metadata in libSQL/Turso, with SQLite still the default and the SQL layer split behind a database adapter. The new adapter batches remote writes into fewer round trips, and the metadata schema check now rejects mismatches cleanly before creating tables or getting stuck behind a busy lock.

### **pnpr adds staged archives, release records, and transparency logs** (1795d7f, 48c459e, 01f000a, 6dfba21, e2aafe5, 6d48526, e3beb72)
Publish now supports pre-staged release archives addressed by integrity, plus release records that include core version fields, signed acceptance statements, and hosted transparency logs with checkpoint/tile/bundle routes. These changes move pnpr much closer to the atomic publication and verifiable-history model described by the RFCs.

### **Repeat installs now trust recorded manifests instead of rereading everything** (1201425, 144a9da, 2315dce, 5162526)
The optimistic repeat-install path records more manifest state, including file stats and key top-level fields, so unchanged projects can be skipped on subsequent installs. It also now notices `extendNodePath` and workspace-version changes when they matter, avoiding stale bin shims and unnecessary reinstall churn.

### **pnpm update and lockfile checks get a batch of correctness fixes** (99017ae, aa58027, 3668cb6, a2d9eb5, fc8ee94, f3349a7, bbc34bd, fe21667, 6197b4f, 1651d69, 660a106, 0bcbee6, 725386e, 28bab4b, 5bd38b1, 8d4a5c2)
pnpm fixed several user-visible edge cases: dependency updates now preserve the right operators for Cargo and Python, add falls back more sensibly, dedupe/check keeps the lockfile read-only, and lockfile verification handles tricky catalog, prerelease, and workspace-link cases. The resolver and executor also picked up peer-identity, bin-path, command-shim, and self-update fixes that prevent incorrect reuse and flaky failures.

### **Store handling is more correct across layouts and inputs** (be8ec14, 539052b, 10be73d, 76138ff, 31fd4dd, a80532e, 7c823b0)
Store commands now understand staged tarballs, verify the global virtual store using the actual layout, and avoid pruning packages or aliases that are still in use. `store add` is blocked under `frozenStore`, and the native git fetcher/store-index path is hardened against key spoofing.

### **Other misc changes**
- Test coverage updates for pnpr metadata, repeat-install records, store behavior, git subdir installs, executor races, and libSQL replication.
- CI and tasking updates, including crate-layer checks, auth linting, and workflow cleanup.
- Docs and configuration updates, plus small dependency bumps and patch rebases.
