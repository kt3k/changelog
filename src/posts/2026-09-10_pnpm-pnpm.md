### **Safer installs and faster warm restores**
`bc11676` defers store-file verification until the install plan knows which snapshots will actually be materialized, cutting a lot of unnecessary stat calls on warm global-virtual-store restores. `efa1d1d` also speeds up warm installs by skipping unread package-map writes unless the feature is enabled and caching global virtual-store slot paths instead of recomputing them every run.

### **Git source fetches are deduplicated per install**
`927c6ec` shares Git checkout acquisition across resolution and materialization for packages coming from the same repo and commit. That means one download per install instead of one per package, while still keeping each package's prepare script isolated in its own copy.

### **Update now preserves version operators**
`0c2694b` fixes `pnpm update <name>@<version>` so it keeps the range operator already declared in `package.json` instead of rewriting selectors as exact versions. It also preserves `jsr:` and npm alias prefixes, which prevents updates from silently changing manifest semantics.

### **Hoisted installs stop redoing work**
`2053841` makes repeat hoisted installs leave already-present packages alone instead of re-importing the whole tree. That avoids needless package replacement, keeps lifecycle scripts from rerunning for unchanged packages, and still reimports the cases that must move: missing dirs, changed versions, `file:` deps, and patched packages.

### **GitHub Actions update handling is hardened**
`8d4b588` isolates GitHub Actions dependency handling and adds safety checks so workflow action refs are not updated if they change during resolution. It also tightens homepage URL handling so server credentials are no longer exposed and non-loopback HTTP is rejected.

### **Package-name validation was split into its own crate**
`4ffe9bc` extracts npm package-name validation into a dependency-free crate and rewires consumers to use it directly. That trims resolver/parser baggage from validation-only paths while preserving the old public module paths via reexports.

### **Workspace and resolver behavior gets several correctness fixes**
`81420fc` restores respect for workspace linking depth, `40b1463` fixes shorthand `workspace:` peer ranges by treating empty `^`/`~` selectors as `*`, and `0c690a9` keeps peer hoisting range-compatible to avoid lockfile churn. `97af347` also fixes script commands in directories that contain a Cargo or Python manifest by resolving the surrounding npm project correctly.

### **Security and robustness fixes in dependency restoration**
`0d2b1db` closes a symlink-target overwrite hole in the copy tier, `537a281` rejects path traversal via global-virtual-store slot suffixes, `1baadf1` and `32e3b21` improve fallback behavior when hardlinking/reflinking is denied or exhausted, and `c3c4d80` adds a cross-device-safe rename path for nested `node_modules` during imports.
