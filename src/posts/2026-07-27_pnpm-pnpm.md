### **Fix local tarball installs that were silently skipped** (7befc73)
`pnpm install` now correctly extracts and records `file:*.tgz` dependencies even when the tarball is the only source of the package manifest. This fixes a nasty failure mode where installs could succeed but leave no lockfile entry and a dangling symlink.

### **Make store-index keys match pnpm 11 for non-registry deps** (ec389f6)
URL, git-host, and `type: git` dependencies are now keyed by their bare resolution id instead of a `<name>@...` form. That restores cross-version store reuse and avoids redundant downloads, extractions, and imports when switching between pnpm stacks.

### **Reject integrity-less tarballs during lockfile verification** (cd09b1c)
The verification gate now catches tarball entries missing `integrity` up front and reports all offenders in one `ERR_PNPM_MISSING_TARBALL_INTEGRITY` error. That closes a gap where bad entries could pass verification and only fail later during fetch.

### **Fix recursive `--parallel` handling in the Rust CLI** (5534ee4)
`--parallel` is now recognized as a recursive-run option instead of being mistaken for a script name. The change also applies the expected no-sort behavior and runs selected projects concurrently while keeping result ordering deterministic.

### **Honor `scriptShell` for lifecycle scripts** (1dbc196)
Lifecycle scripts spawned during install now use the workspace's configured shell instead of always inheriting the platform default. This fixes cases where projects worked with `pnpm run` but failed during install-time script execution.

### **Preserve inherited `TMPDIR` in script environments** (960aba3)
The executor no longer overwrites a user-provided `TMPDIR` when `unsafePerm` allows inheritance. When unsafe permissions are disabled, it still substitutes the per-package temp directory as before.

### **Fix `licenses list` parity with TypeScript pnpm** (81411d3)
`pnpm licenses list` now scans every workspace importer by default, not just the active one, and applies the same platform filtering and dependency-group priority rules as the TS CLI. This closes gaps that caused missing dependencies and incorrect license classification in large workspaces.

### **Other misc changes**
- Licenses parity follow-up: legacy `licenses` fields and conventional license-file detection in pacquet.
- Dedupe/check output ordering stabilized to match canonical lockfile-key order.
- Public hoisting derived from `shamefullyHoist` after config merge.
- Config warnings moved to stderr.
- Unicode formatting controls stripped from terminal output.
- Bare workspace package adds, recursive script listing, pnpmfile checksum validation, git integrity handling, libc metadata shape, and several other parity/test fixes.
