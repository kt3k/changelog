### **Pacquet CLI gains a full `pkg` command** (7a27027)
Ported `pnpm pkg` to the Rust CLI, including `get`, `set`, and `delete` behavior over package.json property paths. This closes a major gap for Rust-based consumers and makes the CLI’s package-manifest editing flow available outside the TypeScript implementation.

### **Rust engine now has Node API bindings** (de1371d)
Added the `pacquet-napi` cdylib and `@pnpm/napi` wrapper so Node.js consumers can drive the Rust engine programmatically. This is a significant platform expansion: it exposes install/resolve/pack-style engine operations to JavaScript callers and ships the new artifact in release automation.

### **`pnpm self-update` now respects trust policy and recovers broken cached slots** (dcfc611)
Self-update now honors `trustPolicy=no-downgrade` by resolving pnpm with the same full-metadata trust checks used by normal installs. It also avoids aborting on unusable cached engine slots, falling back to a fresh install when the cached wrapper cannot be safely reused.

### **Standalone pnpm downgrades are fixed** (25bd5c3)
Global install conflict handling now treats `pnpm` and `@pnpm/exe` as replacement aliases for the standalone CLI pair. That lets pnpm v12 cleanly downgrade to v11 instead of tripping over bin ownership differences between the two packaging layouts.

### **Pacquet now supports pnpm repo CI script fixtures** (6fbbebf)
Script dispatch can now read `package.yaml` fixtures and workspace discovery covers the repo’s CI script layout, instead of assuming every manifest is `package.json`. This fixes real pnpm repo CI paths that were falling through to `exec` and reporting commands as missing.

### **Recursive `list` works again for workspace chunking** (692c449)
`pn -r list --depth=-1 --json` now honors recursive selection and allows hyphen-prefixed depth values through parsing. This unblocks the pnpm repo’s test chunker, which depends on recursive project listing to discover workspace test scripts.

### **Runtime tarballs now persist synthesized manifests** (1219c99)
When fetching Node/Bun/Deno runtime archives, pacquet now persists the synthesized `package.json` into the store index instead of only keeping it in memory. That fixes warm installs and bin linking for archives that ship no manifest of their own.

### **NAPI install options expose `linkWorkspacePackages`** (be8e8ea)
The Node binding now accepts `linkWorkspacePackages` and maps it onto the Rust config model, including the `deep` mode. This gives programmatic consumers control over workspace-package resolution parity with pnpm’s config.
