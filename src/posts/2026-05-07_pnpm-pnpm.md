### **pnpm-render can now render NDJSON from stdin** (6836547)
`@pnpm/cli.default-reporter` now ships a `pnpm-render` bin that reads pnpm-shaped NDJSON from stdin and renders it with the default reporter. That makes it easy for external tools emitting `pnpm:*` log records to reuse pnpm’s console formatting, including command-specific rendering via an optional verb argument.

### **Tarball downloads now avoid encoded-body size mismatches** (0cf64b7)
The tarball fetcher now requests `Accept-Encoding: identity` and skips the strict `Content-Length` check when a response is content-encoded. This fixes `ERR_PNPM_BAD_TARBALL_SIZE` on registries that serve compressed tarballs or misreport lengths, restoring reliable installs from affected registries.

### **Publish packing strips semver build metadata before packing** (8eb1be4)
`pnpm publish --provenance` now removes `+<build>` metadata from the packed version so the tarball, packed manifest, and provenance subject all agree. This closes a registry rejection case for canary-style versions like `1.0.0-canary.0+abc1234`.

### **Lockfiles keep tarball URLs that cannot be derived** (b682b6e)
Lockfile resolution now preserves non-derivable tarball URLs even when `lockfileIncludeTarballUrl` is false, instead of dropping them outright. That prevents frozen-lockfile installs from failing on registries like GitHub Packages and JSR where the tarball path can’t be reconstructed from name, version, and registry alone.

### **Reporter pipeline gains more pnpm log channels** (91812dc)
Pacquet’s reporter now emits additional portable events, including package manifest, root, stats, and request-retry logs. These fills gaps in the event stream and make downstream rendering and tooling behave more like upstream pnpm.

### **`.modules.yaml` implementation lands** (2af4cf8)
The previously stubbed `node_modules/.modules.yaml` support is now implemented, with substantial new parsing, writing, and test coverage. This is a foundational install-state piece and a major step toward pnpm-compatible workspace metadata handling.
