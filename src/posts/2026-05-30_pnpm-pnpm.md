### **Remote https-tarball direct dependencies now install end to end** (394ee27)
pnpm can now resolve and install non-registry remote tarball direct dependencies, computing their sha512 integrity and reading `package.json` during resolution so the lockfile records the right metadata. The change also hardens lockfile behavior around unrelated installs, preserving integrity so later `--frozen-lockfile` runs don't fail closed.

### **pnpm-agent and pnpr move to PolyForm Shield** (d99b725)
The `pnpm-agent` and `pnpr/` trees were relicensed from MIT to PolyForm Shield 1.0.0, with bundled LICENSE files and updated package metadata to point at them. The repo README and contribution docs were updated to make the license boundary explicit and describe the new contribution terms.

### Other misc changes
- License and packaging metadata updates for `pnpm-agent`/`pnpr`.
- Documentation refreshes and generated manifest adjustments.
