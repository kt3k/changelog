### **pnpr adds OIDC and keyless publishing** (4ed7a43)
Administrators can now configure OIDC providers and bind subjects/claims to registry users, enabling browser-based sign-in and workload publishing without persistent tokens. The implementation adds a full auth flow, short-lived sessions, and extensive validation around token audience, timing, and cookie handling.

### **pnpr expands OCI registry support and operations** (3610b85, 85fb54b, 06ecd06, 6e87cbf)
OCI becomes a first-class hosted ecosystem with image push/pull support, referrers, blob mounts, ranged reads, pagination, and upstream/proxy workflows. The registry also gains operational tooling for resumable S3-backed uploads and offline garbage collection, which matters for real deployments because it closes the gap between “can serve images” and “can run a durable image registry.”

### **Staged publish approvals are now claimed once across replicas** (8760cfa)
Approving a staged publish now conditionally claims the shared record before replaying it, so two replicas can’t both publish the same stage. That also means a rejection that lands during approval can stop the publish instead of racing past it.

### **pnpm fixes several install and routing regressions** (5adbbbe, 54d7268, 7f3e8d9, a7c739f, f47b7c7, 2a47c58, 4d539d8, c1a4cc0, 11abf2a, 87ad068, 1aab19b, 9f8070d, 06a9de0, ee1af01)
Notable fixes include JSR packages resolving through the built-in registry, `fetchTimeout` behaving as an inactivity timeout, invalid CA material no longer aborting installs, and patch-added build scripts now going through approval. The day also restores several CLI behaviors and hardens pipeline cache-key generation against malformed inputs.

### **Other misc changes**
- Added Android, FreeBSD, PPC64LE, s390x, and riscv64 native build targets.
- Dependency, lockfile, workflow, and test updates.
- Misc. docs and fixture updates for the new pnpr/pnpm behaviors.
