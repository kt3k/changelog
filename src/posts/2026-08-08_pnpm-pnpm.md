### **Self-update now works with mirrored registries** (f41d01e)
pnpm’s package-manager bootstrap can now switch versions even when the registry serves tarballs from another host or omits signature metadata. That restores `pnpm self-update` and automatic `packageManager` switching on private mirrors/feed proxies that previously failed integrity or engine checks.

### **dlx ignores the caller project’s patches** (d98142c)
`pnpm dlx` and `pnpm create` no longer inherit `patchedDependencies` from the invoking workspace, which had been causing cache installs to look for patch files under the throwaway dlx directory and fail. The package is installed unpatched as intended, avoiding a project-level config leak that could break every dlx run from patched repos.

### **Ecosystem E2E now passes under the global virtual store** (9b20598)
The built-in compatibility extensions were expanded so Angular and Nuxt builds can resolve undeclared `tslib` and `unplugin` dependencies in the global virtual store. The workflow also installs a newer Node runtime before running the matrix jobs, matching the bundle’s minimum and unblocking the suite.
