### **Send Content-Length on empty S3 uploads** (dfd7fe8)
Zero-byte uploads now set `Content-Length: 0` explicitly before sending the PUT, which fixes GCS rejections with `411 Length Required`. This unblocks publishes for packages that include empty files like `.deps.ts` or `.gitkeep`.

### Other misc changes
- Added a regression test covering empty uploads against a server that requires `Content-Length`.
- S3 upload path now explicitly sets the request header when forwarding through reqwest/hyper.
