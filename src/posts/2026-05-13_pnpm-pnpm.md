### **Workspace installs now anchor correctly and add `--node-linker`** (8881842, f33838c)
Pacquet now resolves workspace roots before applying install defaults, so running from a subdirectory still writes `node_modules` and the virtual store under the workspace root. It also adds a `--node-linker [isolated|hoisted|pnp]` CLI flag that overrides config per invocation, aligning install behavior with pnpm's own flag.

### **Lockfile support expands for pnpm v11 runtime deps and freshness checks** (5483cc1, 0f51f82)
The lockfile parser now understands `runtime:`-prefixed peer versions used by pnpm v11, which is required to load real v11 lockfiles containing runtime dependencies. Separately, frozen-lockfile installs now verify the wanted lockfile still matches `package.json`, preventing stale lockfiles from silently producing the wrong `node_modules` tree.

### **Runtime packages and hoisted installs gained major coverage** (13a6970, be759bf, c7ab26a, 3b9f597, 9c67bc8, ff8f458, 4cf6675, 0a89e13)
The hoisted linker was completed and its dep-graph types were tightened with a `PkgIdWithPatchHash` newtype, plus installability and prev-graph diffing support for more pnpm-like hoist behavior. Runtime package handling also advanced with bin-link support for runtime archives and the `hoistPattern` / `publicHoistPattern` install path.

### **Network stack now matches pnpm's auth, proxy, and TLS behavior much more closely** (9a0199c, 6d9d0ad, 52364d4, a603a52, b33a50f)
Pacquet now handles registry auth, proxy cascading, per-registry TLS overrides, local-address selection, and a rustls-based client-cert path that accepts the same PKCS#1 / PKCS#8 / EC key formats pnpm does. These changes remove several real-world private-registry and enterprise-network blockers.

### **Git-hosted package installs became first-class** (540fa76, 48a134f, cad3782, 006f9fd, b61c90d, 918e791, 5d023a0, d2cdb8d)
Git dependencies can now be fetched, prepared, packed, and warmed through the CAS path, including shallow-clone defaults and a more faithful packlist implementation. The fetcher also picked up a faster CAS re-import path and broader test coverage for real npm/git behavior.

### **Optional-dependency handling and GVS support were filled in** (ca88aff, 9701001, 91e537f, 2794696, 20455eb, 3fe272f, 2c513ad, 00d1351, 03499dd, 11f9a27, 5b4c090)
A long optionalDependencies umbrella landed across installability, skipped-snapshot persistence, fetch-failure swallowing, and lockfile filtering, making frozen installs behave much closer to pnpm. In parallel, global virtual store foundations, pruning, and activation were wired through the install path, along with a correction to the `enableGlobalVirtualStore` default.

### Other misc changes
- Test and fixture updates across hoisting, git fetcher, TLS, workspace, and lockfile behavior.
- Small type/compile fixes in package-manager and lockfile internals.
- Dependency/Cargo.toml bumps and housekeeping around new crates and test utilities.
