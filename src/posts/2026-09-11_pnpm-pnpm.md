### **Fix `update --no-save` under strict release-age checks** (7737634)
`pnpm update --no-save` now only fails under `minimumReleaseAgeStrict` when it actually selects an immature version. That unblocks lockfile-refresh workflows like Renovate while keeping the refusal in place when a cutoff-violating pick would need to be recorded.

### **Auto-install missing transitive peers across workspace depths** (2b39d19)
`pnpm install` now fills in missing transitive peers even when workspace projects share dependencies at different depths. The resolver also avoids incomplete duplicate peer contexts in the lockfile, fixing a case where deeper resolutions could miss peers provided by an ancestor.

### **Extract Python installation into its own crate** (53acaaf)
Python package installation was split out of the CLI into a dedicated `pnpm-python-installer` crate, with manifest handling, resolution, wheel fetching, interpreter operations, and environment publication moved together. This makes the Python path cleaner to maintain and reuses the new crate from `add`, `install`, `exec`, and `run` paths without changing behavior.

### **Cap Rust nesting depth at three and refactor violations** (e29016f)
The Rust workspace now enforces a stricter nesting-depth rule via Dylint, backed by an updated style guide. A broad refactor across CLI, restore, network, and test code reduces deep nesting with guards and helpers while preserving existing semantics.

### **Route Cargo through pnpm-managed crates in CI** (822f2dc)
The repo now commits the pnpm-managed Cargo source block and adds a CI action to install Cargo dependencies consistently before Rust jobs. That keeps `.cargo/config.toml` from churn after installs and ensures jobs resolve crates from `.pnpm/crates` instead of falling back to Cargo's registry.

- Dependency/lockfile updates and toolchain bumps (1 commit)
- Minor Rust/CI style and workflow tweaks tied to the refactors
