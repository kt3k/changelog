### **API migrates off sqlx to tokio-postgres** (d7063a0)
The API now uses `tokio-postgres` with `deadpool-postgres` instead of `sqlx`, specifically to avoid named prepared statement issues through Cloudflare Hyperdrive. This is a major infrastructure change: migration handling is replicated, query type mismatches were fixed, and tests were added to cover the affected queries so the swap can be landed and reverted without schema changes.

### Other misc changes
- Removed `sqlx`-specific setup and checks from CI and contributor docs
- Updated workspace membership and README instructions for the new migration flow
- Regenerated/removed numerous `.sqlx` query metadata files
