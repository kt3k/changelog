### **DataView.byteLength/byteOffset now return 0 on detached buffers** (5593a63)
The spec now requires these accessors to return +0 instead of throwing a TypeError when the underlying ArrayBuffer is detached or the view is out of bounds. That aligns the observable behavior with the new normative note and removes a surprising exception path for DataView users.

### **PR preview deployments shrink by externalizing TOCs** (0de5cb1)
Preview pages now move their duplicated table-of-contents markup into generated asset scripts, cutting the repeated payload that was pushing GitHub Pages toward its size limit. The deploy flow also gained mutex protection so main-preview deployment work doesn’t get lost when multiple pushes race.
