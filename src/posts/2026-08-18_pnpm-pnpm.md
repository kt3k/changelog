**`pnpm init` now writes an exact pnpm pin for Corepack** (25c1286)
This fixes newly initialized projects failing under Corepack because `devEngines.packageManager.version` was being written as a caret range. The init flow now records the exact pnpm version and keeps workspace-root behavior intact.

**Forced re-resolves now keep already-satisfied lockfile edges pinned** (a615254)
When config drift forces a full dependency re-resolution, edges whose recorded versions still satisfy their ranges no longer get repointed to the highest locked version. That reduces unrelated lockfile churn and preserves stable resolutions even when subtree reuse itself is blocked.

**Rust dependency advisory handling was tightened for h2** (bd7d354)
`cargo deny` now blocks vulnerable `h2` 0.4 releases explicitly while keeping the accepted 0.3 copy scoped to the intended libsql path. This closes the hole where the advisory ignore could have masked a fixed 0.4-line regression.

### Other misc changes
- Release/version bumps and lockfile updates
- Test cleanup: replaced mtime sleeps with explicit mtime helpers
- CI/build tooling refreshes, including `cargo-fixit` adoption and GitHub Actions updates
