### **pnpr makes resolver cache auth-aware** (1dd12bd)
pnpr now treats resolve cache entries as authorization-aware and stops forwarding the client's upstream registry credentials to the pnpr server. Instead, the server selects upstream credentials from its own route policy, rejects inline URL credentials, and uses allowlisted routes to decide whether a dependency is public or private.

This tightens the trust boundary for private dependency resolution and changes how pnpr installs are authenticated, so it matters for both security and correctness.
