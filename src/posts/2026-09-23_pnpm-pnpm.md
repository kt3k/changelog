### **Config and install behavior got tighter across the board**
Multiple high-impact fixes landed around config parsing, environment handling, and install-time behavior. Notably, pnpm now honors `reporter` from config, stops expanding env vars in project-controlled `userAgent`, and fixes CI detection and workspace discovery edge cases that could change install outcomes or expose secrets. (e45d1ff, a94a8dd, 0b50a17, 303168d, 33badb1, 312c548)

### **Publish now has availability waiting and workspace-safe publishing**
`pnpm publish` gained `--publish-wait-timeout`, which waits for versions and tarballs to actually become available before continuing, including in recursive publishes. The publish/pack flow also now resolves workspace protocol dependencies even when `node_modules` is absent, making release workflows more reliable. (4992abf, 4b49871)

### **Install, resolve, and audit logic fixed several correctness bugs**
A cluster of resolver and lockfile fixes addresses stale overrides, semver build metadata, peer satisfaction handling, and store-manifest reuse when auth is unavailable. These changes reduce surprising lockfile churn and prevent packages from being incorrectly included or audited under `--prod`/`--dev`. (aaa12cc, 9cd72d2, f267a2f, b3bcb25, 0ea6312, 1af0fc0, ed4cb35)

### **Filesystem and lock handling became much more robust**
pnpm now detects dead directory-lock holders and takes over immediately instead of waiting minutes, retries Windows removals through transient file locks, and falls back correctly when hard-linking or patch-commit linking fails. These fixes remove several classes of hangs and broken cleanup on Windows and cross-device filesystems. (0d3600a, 4abcdd1, 8fad8a3, 8727478)

### **Hoisted, global, and runtime behaviors were corrected**
The hoisted linker now respects custom `modulesDir`, global package scans tolerate missing package directories, Node runtime/shim resolution got updated for `.node-version`, Windows ARM64, and pinned-project self-update behavior, and `pnpm restart` now falls back correctly when no restart script exists. Together these close a number of user-facing rough edges in everyday commands. (b42b8f3, f7818b1, cb02ae2, 8d7294c, 7f107fe, 3c217a9, fe63309, 1b7de8f)

### Other misc changes
- Dependency bumps and lockfile updates
- CI/test workflow and benchmark adjustments
- Docs/help text fixes and small CLI polish
- Regression tests for install, publish, pack, patch, and store commands
