### **Pacquet gets its first publish command** (d1da02e)
Added `pacquet publish`, bringing the Rust port closer to parity with `pnpm publish`. It supports publishing a single package or tarball, plus recursive workspace publishing with dependency ordering, skip logic for private/unnamed/already-published packages, and summary/json reporting.

### **Pacquet now switches to the project’s package-manager version up front** (f8058eb)
`pnpm --version` and normal command dispatch now honor `packageManager` / `devEngines.packageManager` before running, so projects can see the selected pnpm version even for version-only invocations. The switch path was also moved to happen synchronously before Tokio startup when possible, reducing overhead for no-switch cases.

### **Fix self-update to install the right engine wrapper for older pnpm** (dba2255)
`pn with <version>` now selects `@pnpm/exe` for pnpm 6.17.1 through v11 instead of always installing the unscoped `pnpm` package. That avoids runtime failures where the wrapper is missing its host native binary, while keeping v12+ on the unscoped package path.

### **Reporter summaries now respect the active prefix** (ed54ccc)
Pacquet’s default reporter was previously folding workspace install events into the root summary; it now filters summary inputs by the current prefix for normal installs. This brings workspace output in line with TypeScript pnpm behavior while preserving the special cross-prefix flows like global add/remove/update, dlx, and create.

### **dlx now resolves catalog overrides and runtime bins correctly** (3685987)
`pnpm dlx` no longer fails when caller overrides contain `catalog:` references, because those references are resolved against the caller’s workspace catalogs before the cache install severs workspace context. It also rehydrates runtime entries from `engines.runtime` back into the dependency map so installed runtime packages can be located for bin discovery.

### **Skip optional dependency warnings in pacquet’s console output** (91da714)
Pacquet now suppresses skipped-optional dependency warnings instead of printing them, matching upstream behavior for the emit shapes it produces. This removes noisy console output for unsupported platform/build-failure cases that upstream would not surface anyway.

### Other misc changes
- Publish security hardening: redact inline registry credentials in `pnpm publish` output.
- New/revised tests across publish, version switching, self-update, reporter, and dlx paths.
- Minor workspace/config plumbing and dependency updates for new publish and auth-related crates.
