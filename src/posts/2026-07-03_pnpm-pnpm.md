### **pnpr adopts the new registry/package policy model** (02ef9b5)
pnpr is refactored to the RFC-based `registries` model, replacing the older route-level `mounts`/`uplinks` vocabulary and moving package ACLs onto each registry. This is a broad config and server rewrite that changes the public config surface and how registries, routes, and access rules are represented.

### **pnpr merges namespace and ACL into per-registry package maps** (90dd346)
pnpr’s policy model is further updated to the newer per-registry `packages:` shape, combining namespace declaration and access control into one map. That removes the old top-level `packages`/`uplinks` setup and changes how package rules are evaluated, which is a substantial behavior and config shift.

### **Resolvers now reject malformed `jsr:` and named-registry names** (25c7388)
The JSR and named-registry parsers now fail fast on empty scopes/names, path separators, and other package-name shapes npm would reject, instead of letting malformed names flow into URLs and cache paths. This closes a correctness hole that could otherwise produce invalid registry access and filesystem paths.

### **Workspace version mismatches now show the available local versions** (a6c4d5f)
When registry lookup fails for a dependency that exists in the workspace but only at non-matching versions, pnpm now surfaces `ERR_PNPM_NO_MATCHING_VERSION_INSIDE_WORKSPACE` with the workspace versions listed. That makes the failure actionable instead of hiding the useful local-context hint behind a generic registry error.

### **Non-interactive OTP errors now preserve auth URLs in JSON output** (1e81761)
When web auth falls back to a non-interactive error, pnpm now carries `authUrl` and `doneUrl` through to the JSON error payload instead of dropping them. This improves automation and debugging for OTP-gated logins, while also sanitizing the URLs before display/storage.

### **`pnpm issues` now aliases `pnpm bugs`** (e2e3c81)
The CLI gains an `issues` alias for the `bugs` command, so both names resolve to the same bug-tracker opener. The alias is wired into help text and command parsing, making the more discoverable command name available without changing behavior.

### Other misc changes
- Security advisory allowlist updates for quick-xml-related RustSEC entries
- CLI/test cleanup and renamed pnpr identifiers across docs and helpers
- Additional tests for the resolver, web-auth, and CLI alias behavior
