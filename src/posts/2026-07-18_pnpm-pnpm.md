### **Pacquet now supports `install-test`** (9f193ae)
Adds a native `install-test`/`it` command to the Rust CLI, chaining install and test with the same install arguments. This closes a parity gap with the legacy CLI and makes the command available in recursive workflows too.

### **`pnpm licenses` arrives in the Rust CLI** (f896981)
Implements the `licenses` command in pacquet with tabular and JSON output, workspace recursion, and author/homepage extraction from package manifests. That expands the Rust port's user-facing command coverage beyond the install/query core.

### **Workspace filters are now honored in pacquet installs** (9657c88)
Fixes recursive install flows so selected workspace projects stay selected through dispatch and package-manager execution, rather than being split up or dropped. This prevents lockfile truncation and unintended manifest mutations outside the requested filter set.

### **`--frozen-lockfile` now accepts auto-installed peers** (2bc4dd5)
Fixes a regression where peer dependencies materialized by `auto-install-peers` were misread as removed dependencies during freshness checks. Frozen installs should now succeed when the lockfile matches pnpm's expected peer materialization.

### **Conditional metadata requests now use HTTP dates** (0dbf7e6)
Fixes `If-Modified-Since` on the Rust resolver to send a proper HTTP-date instead of the mirror's raw ISO-8601 timestamp. That lets registries return `304 Not Modified` and avoid re-downloading large packuments.

### **Optional peers from `peerDependenciesMeta` now hoist correctly** (6156ffd)
Fixes optional peers that are implied only through `peerDependenciesMeta` so they can be deduped and hoisted like other peers. This brings fresh resolves and lockfile reuse back into alignment for common optional-peer patterns.

### **Release workflow is hardened for multi-tag publishes** (b55e0d8)
Changes release planning to publish only the product named by each version tag, and scopes concurrency per ref so simultaneous tags don't evict each other. It also validates that tags actually point at the commit being released, reducing the risk of cross-tag mispublishes.

### **Lockfile reuse no longer corrupts denied edges** (aeaaccb)
Fixes a race in non-frozen reinstalls where a denied reuse edge could read another edge's synthesized result from the wanted-dep cache and collapse the subtree. The fix keeps reused resolutions from being mistaken for fresh dependency trees.

### **Versioning ledgers round-trip empty intent lists** (b5c6733)
Fixes ledger entries with no consumed intents so they serialize as `intents: []` and can read older bare forms back in. This prevents `pnpm version -r` from breaking on previously committed ledger entries.
