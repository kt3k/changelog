### **Leap-year logic split into a dedicated boolean op** (828d35d)
The time abstract operation previously known as InLeapYear was refactored into IsLeapYear, taking an integer year and returning a Boolean instead of 0/1. Callers like MonthFromTime and DateFromTime now do the YearFromTime step themselves, which makes the leap-year check cleaner and more reusable for other spec work such as Temporal.

### **Break/labelled evaluation simplified with implicit normal completion** (70cc341, b11f998)
The control-flow algorithms for BreakableStatement and LabelledEvaluation were rewritten to return directly when a matching break is found, instead of manufacturing NormalCompletion records. Related wording also tightens Completion Record guidance so the [[Target]] field is only meaningful for break and continue completions.

### **Atomics.waitAsync return value clarified** (86b66b9)
The spec now states that Atomics.waitAsync returns an object with `async` and `value` properties, rather than describing it as directly returning a Promise. This better matches the API shape and distinguishes the synchronous and asynchronous result cases.

### Other misc changes
- Fixed an incorrect `!` in IsLooselyEqual (8a3e4aa)
- Corrected an alias name in reads-bytes-from (d8cb877)
- Reworded return-value constraints for essential internal methods (f1124ce)
