**POSIX shell shims now quote paths safely** (e9bee2a)
Generated shims now single-quote interpolated paths and NODE_PATH entries so shell metacharacters like `$`, backticks, quotes, and backslashes stay literal. This fixes relocatable and global shim generation across both pnpm 11 and 12.

**Global installs now expose hoisted dependencies to bin shims** (4970769)
Packages installed with `pnpm add --global` can again resolve dependencies that pnpm hoists for them, instead of failing with module resolution errors. The fix wires the group’s hidden hoisted modules into `NODE_PATH` for direct shims.

**`pnpm peers check` gains a `--global` mode** (17e062e)
Peer checks can now scan globally installed package groups and report issues per group, matching how global installs actually lay out dependencies. The reporter and CLI warnings were updated so users are pointed at `pnpm peers check -g` after a global install/update.

**Cargo updates now skip versions that drop enabled features** (0b27bac)
`pnpm update --latest` no longer rewrites a crate to a version that Cargo can’t resolve because it removed a feature the workspace still enables. Instead, it keeps the current version with a warning unless the crate was explicitly targeted, avoiding failed bulk updates.

**Cargo manifest updates handle multi-line inline tables** (61db547)
`pnpm update` can now rewrite dependency versions inside inline tables that span multiple lines, such as dependencies with a long `features` array. That unblocks update workflows that previously failed on valid Cargo.toml syntax.

**Side-effects restores keep bundled dependencies intact** (aa99d9e)
Restoring from the side-effects cache now preserves files under `node_modules` inside bundled packages instead of treating them as deleted. Warm-store installs should no longer lose bundled dependencies after a build.

**Node version resolution prefers stable releases over prereleases** (8ab51f8)
When resolving a Node.js range, pnpm now chooses the highest stable version first and only falls back to prereleases if no stable version matches. That avoids picking alpha/nightly builds when a normal release satisfies the range.

### Other misc changes
- Cargo update workflow now checks crate features against sparse index metadata before editing versions.
- `pnpm add`/catalog handling adjusted for dist-tag entries and workspace adds.
- Agent skill links now use the skill directory name directly.
- Global bin shims and hoisted-module resolution received additional internal refactors/tests.
- Dependency bumps and release-note maintenance (multiple commits).
