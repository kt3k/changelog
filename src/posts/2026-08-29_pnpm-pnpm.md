### **Workspace catalogs can now resolve `workspace:` entries** (789c2d9)
Catalog lookups now accept `workspace:` values instead of rejecting them, so a catalog entry can point at a local workspace package and still resolve correctly. The change updates both the resolver and exportable-manifest logic, plus adds coverage for catalog use in CLI and release flows.

### **Deploy now prunes excluded peers and fetched deps correctly** (74686fb, 43f8aad)
`pnpm deploy` was fixed in two related ways: it no longer carries peer metadata for excluded dependencies, and it avoids materializing dependencies that were only reachable through unselected workspace projects after a fetch. Together these changes prevent filtered deploys from producing invalid or over-inclusive lockfiles.

### **pnpr artifacts are now write-once and overlap-safe** (8e371fa, 7c4e742)
Shared build artifacts now claim an explicit slot based on what they can serve, and publishing into an already-claimed overlapping slot returns `409 Conflict`. This closes the hole where a broader or higher-floor artifact could silently change what later installs execute.

### **Automatic pnpm version switching no longer leaks to children** (320a8cd)
When pnpm auto-switches versions, it now preserves the parent environment for descendant pnpm processes instead of forcing them onto the same pinned version. That lets subcommands pick the correct version for their own project directory.

### **Network clients now keep TLS routing and redirect behavior paired** (779bcaf)
The network layer was refactored so each registry route carries its TLS config and redirect/no-redirect clients together in one structure. This reduces route drift, removes an extra lookup on routed requests, and keeps private key material out of the derived client debug output.

### **N-API peer-issues calls now use typed boundary validation** (16ee230)
`getPeerDependencyIssues` now accepts a structured N-API object instead of raw JSON, preserving proxy and network settings while rejecting malformed input earlier. It also range-checks the length fields that were previously vulnerable to numeric overflow during conversion.

### **CI/test dependency and scheduler adjustments were partially reverted** (1d355de, a9cb924, 9c718da, 6d90c71, 7dc607a)
A workspace task scheduler adoption was reverted, Jest was pinned to 30.4, and a lockfile trust exception was added for a manually published `fastq` version. There was also a release cut and assorted dependency/workflow refreshes.

### Other misc changes
- `fs-packlist` now respects manifest file allowlists for changelogs.
- Trusted remote artifact lockfile pins were removed from the install flow.
- Minor test and workflow updates around catalogs, deploy, pnpr, and N-API.
- Dependency bumps and release/changelog file updates.
