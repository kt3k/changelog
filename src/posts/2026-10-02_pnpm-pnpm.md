### **pnpm login no longer leaks credentials on redirects** (658dbc3)
`pnpm login` now avoids forwarding credentials in the request body when a redirect crosses origins. That closes off a subtle credential exposure path during authentication.

### **pnpm now supports StackBlitz WebContainers** (658dbc3)
pnpm can now run as WebAssembly in StackBlitz WebContainers, including when install scripts are disabled. The change ships new WASM toolchain and release workflows so the WebContainer runtime can use pnpm automatically.

### **Optional dependencies now fail closed when their subtree is unresolved** (9095949)
If a dependency under an optional package can’t be resolved from the registry, pnpm now drops the nearest optional dependency and its subtree instead of failing the install. This matches npm’s behavior and avoids inconsistent lockfiles across platforms.

### **pnpm revalidates uncacheable registry metadata instead of redownloading it** (278cba7)
Metadata responses that forbid reuse are now revalidated with conditional requests, so installs can get a `304 Not Modified` instead of downloading and parsing every packument again. That should materially reduce repeated install cost on registries or proxies that mark metadata as uncacheable.

### **Release-age metadata now keeps its full ETag** (1435ce4)
Packages upgraded under `minimumReleaseAge` now preserve and reuse the full packument ETag for revalidation. This fixes a loop where abbreviated metadata would replace the cached full document and force repeated full downloads.

### **Optional dependency fetch failures now warn clearly** (6d72710)
When an optional package can’t be fetched, pnpm now emits a warning and records a `fetch_failure` skip reason instead of silently linking a broken dependency. The skipped package is also no longer counted as added, which makes install output and state match reality.

### **Android file locking now uses flock** (b2ef6cb)
pnpm now takes file locks on Android via `flock`, avoiding Rust’s `Unsupported` lock behavior there. This unblocks installs that previously failed when the store-operation or metadata locks were acquired.

### **Interactive update prompts now cap the Workspace column** (e479d58)
The update UI now bounds the Workspace column so a dependency shared across many projects doesn’t blow past terminal width. That keeps prompt redraws aligned with what users actually see.

### **Docs sync is now safer and release-driven** (d4db285, 5567c62, 48cea86)
The docs sync flow was tightened so a release-triggered job runs the default-branch workflow instead of the tagged commit’s version, reducing the risk of untrusted release-state influencing token-protected steps. Release publication now also syncs documentation from GitHub release events and publishes composed release pages to pnpm.io.
