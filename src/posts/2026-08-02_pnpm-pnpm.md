### **Registry-qualified lockfiles fix package substitution risk** (2d30dd6)
Packages resolved from named registries are now keyed by registry as well as name and version, so different registries can no longer collapse onto the same lockfile entry. This closes a package-substitution hole and changes lockfiles for projects using `namedRegistries`; the commit also adds a built-in `npmjs:` alias and rejects shadowing reserved specifier prefixes.

### **Install now falls back to bundled CA roots** (21c8ddd)
`pnpm install` no longer crashes when the system trust store is empty or missing, such as in minimal containers or sandboxes. It keeps the platform verifier first, but falls back to the Mozilla roots bundled with the binary so online and offline installs keep working.

### **CLI accepts npm's `--prefix` and `--store` flags** (10481de)
The Rust CLI now recognizes npm-compatible spellings for `--prefix` and `--store` instead of rejecting them before argument rewriting can happen. That restores compatibility for existing scripts and CI that invoke pnpm with npm-style flags.

### **Workspace resolution becomes deterministic** (641ccd3)
Workspace installs now produce the same lockfile across runs by resolving importer initial waves one at a time. This fixes a nondeterministic peer-binding issue that could make identical installs emit different `pnpm-lock.yaml` files.

### **Peer-hoist resolution gets a major memory/perf pass** (5644b55)
The resolver stops re-walking recorded subtrees for competing occurrences, which prevented peer-carrying dependency chains from expanding exponentially. The fix turns a case that could exhaust gigabytes of memory into one that finishes in tens of megabytes.

### **Peer-hoist loop scans are amortized** (c2b2f15)
Per-importer workspace scans in the hoist loop now reuse snapshot state instead of cloning whole maps every round. That removes a quadratic hot path when auto-installing peer dependencies across large workspaces.

### **Peer-scope checks memoize shared suffixes** (7347789)
The logic that decides whether another importer's walk already covers a missing peer now caches answers per shared chain suffix. This trims repeated ancestor scans in deep dependency trees and speeds up large workspace resolution.

### **Peer-cycle graph now derives names once per package** (5484307)
The final peer-resolution cycle graph is built from package IDs and only rendered to names once per package, instead of once per occurrence. That cuts allocation and work in a phase that runs after the main resolution pass.

### **Occurring package waves are resolved sequentially** (99194c8)
The dependency traversal now canonicalizes child specs before walking them, which keeps equivalent manifests from producing different internal node orders. That stabilizes downstream peer-provider selection in large concurrent workspaces.

### **node-gyp is bundled with the Rust CLI** (dbe2dad)
Install scripts that shell out to `node-gyp` no longer fail with `spawn node-gyp ENOENT` unless an external copy happens to be on `PATH`. The release pipeline now bundles and ships node-gyp alongside the native binary so common native-addon installs work out of the box.

### Other misc changes
