### **pnpm runtime can now be unset** (e72f929)
`pnpm runtime unset <name>` removes runtimes from both project and global state, reusing the existing removal pipelines and cleaning up legacy Node.js links and shims. This closes a gap in the runtime workflow and makes it possible to undo `runtime set` directly.

### **Binary files are now patchable** (66a1999)
`pnpm patch-commit` and `patchedDependencies` now handle binary file changes correctly instead of turning them into mangled text diffs. The patching flow now understands Git’s binary patch format, which matters for packages that ship fonts, images, wasm, or other non-text assets.

### **`pnpm view node` now reads the Node release index** (1601d1c)
`pnpm view node` and versioned variants like `node@22` now resolve against the Node.js release index instead of the npm package named `node`. That makes `view` match what `pnpm add node` installs and correctly supports mirror-based Node downloads.

### **Filtered `pnpm fetch` works with shared lockfiles** (717d1cc)
`pnpm fetch --filter` now respects project selection even when the workspace uses the default shared lockfile. Previously it could fetch every importer anyway; now it builds the same filtered install plan used by other workspace-aware commands.

### **`pnpm config get ca` shows every configured CA** (62f7bdf)
When multiple CA entries are present in `.npmrc`, `config get` and `config list` now preserve them all instead of only the last one. The output now reflects multi-value CA settings as an array, which fixes a misleading view of TLS trust configuration.

### **`pnpm store add` handles legacy tarballs and better errors** (dd21fb0)
The store can now skip valid legacy multiline metadata records instead of failing on older npm tarballs. Failed fetch/extract warnings also identify the tarball involved, which makes batch-store failures much easier to trace.

### **`pnpm audit deprecations` output is grouped and shorter** (416d221)
Deprecated packages with the same message are now grouped into a single block, reducing repeated output in real workspaces. Deep dependency chains are also truncated more aggressively, making audit output much easier to scan.

### **Workspace and config behavior fixes** (171e700, 098aa2b, 370f889, 0e4ec5d, 8276193)
A handful of user-facing fixes landed around delegated workspace settings, sparse/off-disk workspace entries, home-relative cache paths, nested workspace manifest warnings, and macOS quarantine checks. These are mostly correctness and ergonomics fixes rather than new surfaces.

### Other misc changes
- Hoisting limit setting renamed from `workspaces` to `projects` with a compatibility alias.
- Release PRs updated dependencies, Node.js, pnpm, and GitHub Actions pins.
- Small docs/test-only and internal cleanup changes.
