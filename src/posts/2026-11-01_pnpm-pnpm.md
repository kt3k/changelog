### **Reuse store mode reads to cut hardlink syscalls** (9d24536)
`pnpm install` now reuses file modes that the store integrity check already read, instead of stat-ing each store file again before hardlinking. That trims syscall noise on hot-store offline installs and restores the benchmark to the lower call counts seen in earlier pnpm versions.

### **Link the runtime after a `--no-runtime` install** (e74512a)
A plain `pnpm install` now notices when the previous install skipped the runtime and links it on the next run. This closes a repeat-install fast-path bug where the workspace state failed to record the runtime setting, leaving `node_modules/node` missing even though install reported everything was up to date.

### **Save Windows crash dumps from CI test failures** (8d0349f)
Windows CI now configures Error Reporting to write minidumps for crashing test processes, then stages the matching executable and PDB alongside any dump on failure. That should make intermittent fast-fail aborts much easier to diagnose when they only show up in CI.

### Other misc changes
- Benchmark harness updates and syscall-gating logic for the perf regression check
- Test coverage and workspace-state plumbing for the runtime install fix
- Minor dependency/lockfile and workflow adjustments
