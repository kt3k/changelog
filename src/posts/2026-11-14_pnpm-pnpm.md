### **Git deps now reuse the locked commit** (e0e583c)
pnpm’s git resolver now preserves the locked resolution for unchanged git dependencies instead of re-running `git ls-remote` every time. That avoids unnecessary network/auth failures during unrelated lockfile updates, especially for private repos with peer deps.

### **Lockfile merges keep importer metadata** (a27e895)
Merged lockfiles now retain importer fields like `publishDirectory`, `linkDirectory`, and `dependenciesMeta`. This fixes frozen installs after `--merge-git-branch-lockfiles` when those settings are added or removed.

### **`pnpm pkg` works on raw manifests again** (22dbc46)
Package-manifest edits now read and write the project’s on-disk `package.json` instead of a normalized view that injected synthetic runtime deps. That keeps `pkg get/set/delete` from corrupting or dropping fields like `devEngines.runtime`, `engines.runtime`, and empty dep maps.

### **Pipeline cache hashing and restores are fixed** (c5a5e71)
`pnpm pipeline` now handles empty inputs, additive/exclusion globs, lockfile-based task keys, and output restore edge cases correctly. The changes also address cache invalidation for uncacheable dependencies and read-only restored outputs.

### **Config routing and validation got stricter** (ef19ddc)
Global config writes now route keys to the right file, validate structured settings before saving, and better handle protected/credential-bearing values. Workspace-only keys are now rejected from global config with clearer guidance.

### **Package archive and publish path handling hardened** (b2dc134)
`pack --out` placeholder expansion and publish directory handling were tightened to avoid path surprises and traversal-style edge cases. The fix also improves recursive publish behavior when manifest fields are missing or empty.

### **Cargo manifest editing and workspace deps fixed** (ef01d47)
Cargo ecosystem operations now preserve formatting and metadata while editing manifests, and they handle prerelease workspace members plus renamed workspace packages correctly. This removes several sources of corrupted `Cargo.toml` edits and failed installs.

### **GitHub Actions updates now handle partial tags and PURLs** (0c8270f)
Workflow update detection, comment parsing, and package URL routing were all improved for GitHub Actions. The fix also tightens outdated-package handling so tag comments and version selectors resolve more consistently.

### **Agent skills now track local directory deps** (3cc5030)
`pnpm install` and `pnpm approve` can now discover, link, approve, and prune agent skills from `workspace:*`, `link:`, and local `file:` dependencies. This makes skill approval work across more install layouts instead of only the simplest dependency forms.

### **Shell parameter expansion handles escaped quotes/backslashes** (caa2f4e)
The `shellEmulator` now parses escaped backslashes and quotes correctly inside braced parameter expansion. That fixes cases where later substitutions were accidentally skipped or expanded under the wrong quoting state.

### **Registry-qualified names are sanitized in SBOM/licenses output** (a063b50)
`pnpm sbom` and `pnpm licenses list` now strip registry aliases from lockfile versions and resolve named registries explicitly. The output is safer and more accurate, especially when lockfiles include multiple registry namespaces.
