### **pnpr gets trusted proxies, health probes, and graceful shutdown** (0ce4551, 7b38a86)
pnpr now understands trusted proxy chains for client IP resolution, with new config for trusted proxy networks and header selection. It also adds readiness/liveness endpoints and SIGTERM shutdown behavior, so containerized deployments can probe backend health and exit cleanly.

### **Security and auth hardening in pnpr** (583f02a)
This fixes several audit issues at once: auth files now preserve permissions and default to 0600 on Unix, disabled-registration logins return 401 to avoid user enumeration, and bcrypt passwords are capped to avoid truncation hazards. It also tightens package immutability behavior during partial unpublish flows.

### **Filtered installs keep missing workspace importers** (9e13c41)
A filtered install no longer drops lockfile importers for workspace projects that are absent from disk, which matters for sparse checkouts and other partial workspaces. The fix also preserves the related package and catalog entries when the filter happens to include every project on disk.

### **Hoisting no longer lets auto-installed peers steal workspace links** (f2d8a2f)
Workspace hoist selection now reads direct dependency aliases from the wanted lockfile instead of relying on resolved graph entries alone. That prevents auto-installed peers from claiming a workspace package name and then causing stale-link cleanup to remove the workspace hoist.

### **Packlist now matches npm for nested ignores and entrypoint re-includes** (82b8c90, 7c6e546)
fs-packlist now honors nested `.npmignore`/`.gitignore` files even when a `files` allowlist is present, and it correctly re-includes directories referenced by `main`, `browser`, and `bin`. That fixes packages publishing too little or too much depending on where ignore rules and entrypoints intersect.

### **Resolved lockfile reuse and peer splits are fixed** (18c4db7, b63e347)
pnpm now reuses the lockfile when catalogs exist but none are actually referenced, avoiding unnecessary full re-resolution. It also re-splits locked children when a dependency later becomes a peer, so two-step installs match one-step installs.

### **CLI and install behavior becomes less surprising** (5ded3b3, 01e844a, d1accb2, 8b6ef36, 73ca487, c28afa0, aa555c3, 932921c)
This batch fixes several user-visible edge cases: commands that only inspect state no longer create a new manifest, stderr writes no longer abort on broken pipes, detached Windows grandchildren stop inheriting pnpm's stdio, and lifecycle failures are reported consistently under ndjson and silent modes. It also restores proxy/registry flags when resolving pinned pnpm versions, makes the Windows toolchain choice follow rustup's default host, and treats null proxy settings as unset.

### **Store mtimes stop changing on no-op installs** (c4c8eb3)
A no-op install no longer bumps the store root's modification time, which prevents cache systems like GitLab CI from re-uploading an unchanged store after SQLite sidecar churn.
