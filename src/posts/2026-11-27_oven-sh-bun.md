### **Type BoringSSL handles and tighten SSL call signatures** (9f0b413)
Bun’s BoringSSL bindings now use typed handle references instead of opaque pointer conversions, which prevents safe code from fabricating handles and removes a large amount of `unsafe`. The surrounding SSL/TLS code was updated to match the new signatures, making the bindings harder to misuse and easier to audit.

### **Make queued tasks own their payloads** (80edce7)
The event loop task model was refactored so queued work owns what it carries instead of holding raw pointers into later-dereferenced state. That removes a lot of `unsafe` from task scheduling and changes many task types and scheduler helpers to the new ownership model.

### **React Compiler bundling now preserves namespace-member bindings** (302ba1f)
The bundler now tracks import-property uses generated by React Compiler rewrites, so namespace members like `X.name` can still be bound directly to exports without materializing the namespace object. This fixes a real codegen regression and should keep compiled React output both correct and leaner.

### **Thread pool wakeup logic now notices work pushed mid-consume** (d82a8a7)
The pool consumer now rechecks the queue after popping, so a task pushed while the consumer still held the queue can’t be missed. This fixes a hang scenario in dependent work, including cases like FIFO `readFile`/`writeFile` ordering.

### **Build trim fixes end-label handling for ELF and Mach-O** (736fe11)
The binary-trimming pipeline now understands symbols that represent the end of a section/atom, avoiding misreads that could break macOS links or prevent archives from being trimmed. The change also improves ELF strong/weak symbol handling and updates the trimming tests accordingly.
