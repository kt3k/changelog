### **pacquet gets a new `why` command** (ee9fab5)
`pacquet why <pkg>` now shows the reverse dependency tree for a package by inverting the lockfile graph, with cycle detection, deduplication, and a depth limit. This is a user-facing CLI addition that helps explain why a dependency is present.

### **Hoisted installs now match pnpm’s version selection** (83457b5)
The pacquet hoister now uses popularity-based preference instead of first-seen order when multiple versions compete for the root `node_modules` slot, while still preferring direct root dependencies first. That closes a layout parity gap in `nodeLinker: 'hoisted'`, including frozen-lockfile replay behavior.

### **Version-policy exclusions now merge exact-version rules correctly** (fbdc0eb)
`minimumReleaseAgeExclude` and `trustPolicyExclude` now treat multiple exact-version entries for the same package as one combined allowlist, instead of stopping at the first matching rule. This fixes a supply-chain policy bug where split entries could behave differently from an equivalent `||` disjunction.

### **npm resolver now caches disk-fast-path metadata in memory** (fa7004b)
Exact-version resolutions now promote parsed packuments into the in-memory cache, so repeated resolutions in one install avoid extra disk reads and parses. The cache key is also registry-qualified, preventing cross-registry collisions; the `update_checksums` path now bypasses warm memory entries to force revalidation.

### **SBOM output now includes issue-tracker references from `bugs` URLs** (17e7f2c)
`pnpm sbom` now emits CycloneDX `issue-tracker` external references for packages whose manifests declare a valid HTTP(S) `bugs` URL, including the root package when applicable. Email-only or malformed bug contacts are intentionally ignored, and embedded credentials are stripped from published URLs.

### **Clone/reflink imports preserve executable bits** (11ebd9d)
Pacquet now restores execute permissions from the CAS `-exec` suffix after clone/reflink materialization, fixing a Linux path that could leave binaries non-executable. The helper also avoids redundant permission syscalls when the exec bits are already present.

### Other misc changes
- Review guidance/docs/config updates, including a new `REVIEW_GUIDE.md` and bot rule refreshes.
- Rust/Cargo dependency bumps (`ignore`, `which`).
- Lockfile/version refresh for pnpm, Node.js, and pacquet.
