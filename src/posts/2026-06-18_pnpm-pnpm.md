### **Add Node.js package map generation and runtime injection** (0474a9c)
pnpm now writes `node_modules/.package-map.json` during isolated and hoisted installs, including the global virtual store, so tooling can start experimenting with Node package maps. It also adds `node-experimental-package-map` and `node-package-map-type` to control whether pnpm injects the map into Node scripts and whether the map is `standard` or `loose`.

### **Refresh stale transitive pins so incremental installs converge** (fe66535)
This fixes a lockfile non-convergence bug where incremental installs could keep an older transitive dependency pinned even after a direct dependency had moved to a newer version that satisfied the same range. The resolver now refreshes that stale pin during resolution, so repeated installs stop churning and match a fresh install more closely.

### **pacquet now honors NODE_EXTRA_CA_CERTS** (2dd79e3)
The Rust network layer now loads the PEM bundle named by `NODE_EXTRA_CA_CERTS` and adds those certificates to install-time clients as extra trust roots. That restores parity with Node’s TLS behavior for users behind corporate MITM proxies or using self-signed registries.

### **Split PR review automation so fork PRs can be labeled safely** (6ee484e)
The PR review flow was reworked into an unprivileged capture workflow and a privileged `workflow_run` follow-up that runs in base-repo context. This fixes fork PRs that previously couldn’t get review labels or Discord notifications because the review-triggered job lacked write permissions and secrets.
