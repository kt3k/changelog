### **Cold installs and `pnpm fetch` no longer stall on macOS** (5307084)
`pnpm fetch` and cold installs now move the linking pass onto a separate thread instead of blocking the download drain. That prevents slow APFS link passes from pausing in-flight downloads, which should cut wall time and reduce spurious slow-download warnings.

### **Workspace-relative `workspace:` paths now resolve from the injected package directory** (b7952df)
When `injectWorkspacePackages: true` is enabled, a relative `workspace:` dependency such as `workspace:../lib-a` is now resolved relative to the package that declares it. This fixes installs that previously looked next to the importer instead of the injected package and failed to resolve the target.

### **`pnpr` now accepts OIDC workload issuers without an authorization endpoint** (60582db)
OIDC discovery no longer requires `authorization_endpoint` for workload verification, which unblocks GitHub Actions-style issuers that only publish issuer metadata and JWKS. Requests that previously died with a 500 during discovery should now verify successfully.

### **`pnpr` now times out libsql auth dials and retries startup** (88e3b16)
Startup no longer waits for kernel TCP retransmissions when the auth database is unreachable. Each dial now times out after 10 seconds and is retried with capped backoff, making transient network loss much less likely to turn into a full outage.

### **`pnpr` fixes tar-registry publish and unpublish behavior** (ed4fe54, abe7858)
The tar registry now preserves and restores tarball integrity data when packuments are rewritten, and partial unpublish/deprecate flows correctly delete tarball blobs even when `dist.tarball` is missing. That closes gaps where metadata and blobs could drift out of sync or tarball cleanup could be skipped.

### **`pnpr` stores token last-used updates off the request path** (3bca7ff)
Token-authenticated requests no longer await a database update before the handler runs, and last-use writes are throttled to at most once per minute per token. This removes avoidable latency from authenticated traffic, especially with libsql replicas.

### **Store pruning is now hardened against directory symlink swaps** (049d374)
`pnpm store prune` now keeps cache directories open while removing metadata, so path replacement attacks can’t redirect deletion through a symlink inserted after the initial check. This is a meaningful security hardening for local store pruning.

### **`pnpm add` and config handling now respect several previously ignored settings** (6d736a0, 6ab3c27, 7f99e75, c053943, da18702, 359ff10, 22f6e06, 7fbde8b, 0e85843)
The day also includes a cluster of user-facing correctness fixes: versionless `add` now honors the configured `tag`, `runtime: false` is read from YAML/env/config, `strictSsl` and `localAddress` are read from YAML settings, `help -a` works again, lowercase save aliases are accepted, recursive runs honor `requiredScripts`, and `pnpr config check` reports auth/default-registry settings more accurately. Store prune now also removes cached metadata as expected.
