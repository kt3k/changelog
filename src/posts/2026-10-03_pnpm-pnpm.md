### **Install now runs project lifecycle scripts on repeat up-to-date installs** (78cd790)
When `optimisticRepeatInstall: false`, an already-up-to-date `pnpm install` now still runs each project's own lifecycle scripts like `prepare`. This restores the expected refresh behavior for hooks and codegen workflows that depend on install-time scripts.

### **pnpm self-update now refuses Homebrew-managed installs** (53428ea)
`pnpm self-update` now detects when pnpm itself was installed by Homebrew and fails with a `brew upgrade ...` hint instead of installing a shadow copy elsewhere. That avoids the old success-but-no-op behavior where the Homebrew binary on PATH kept winning.

### **Changed-project filtering now preserves Git pathnames correctly** (efbe96f)
The workspace filter now consumes Git's machine-readable filename output, so escaped/unicode/literal paths are interpreted the same way Git reports them. This fixes changed-project selection in repos with renamed files, nested workspaces, and Git pathname quirks.

### **[<since>] filtering works again on older Git versions** (9154a91)
The changed-packages selector now only passes `--no-relative` to Git 2.28+ and emits a clearer error on older versions. That restores `...[since]` filtering on Git 2.24–2.27 instead of failing with a usage error.

### **Audit signatures follow redirect targets' TLS settings** (e2fef7f)
`pnpm audit signatures` now fetches registry signing keys with the redirect hop's own auth/TLS context, instead of forcing the original registry's settings onto the final URL. This fixes failures against registries that redirect keys to registry.npmjs.org, including GitLab setups with scoped CA bundles.

### **GitLab provenance now includes invocation parameters** (10e6d06)
Publish provenance statements for GitLab CI now include the invocation.parameters block npm expects to verify against the Fulcio certificate claims. That fixes 422 failures for provenance-enabled publishes from GitLab runners.

### **Quay OCI pulls now allow CDN redirect hosts** (078c0aa)
`pnpr` now allows Quay's CDN redirect hosts for OCI layer downloads, including `cdn.quay.io` and `cdn01` through `cdn06.quay.io`. That unblocks Quay-based image pulls that were previously rejected with 502s.

### **Homebrew and corepack are treated as externally managed** (53428ea)
The self-update path was refactored to reject any pnpm instance whose updates are owned by another tool, covering both corepack and Homebrew. This prevents silent divergence between the updated binary and the one actually executed.

### **WebContainer runtime is split into `@pnpm/wasm`** (ef7d3c5)
The 47 MB WebAssembly runtime no longer ships inside the native `pnpm` and `@pnpm/exe` packages; it is now published separately as `@pnpm/wasm`. That cuts the native wrappers back to a much smaller unpacked size and keeps WebContainer support available as an opt-in package.

### **Install pipeline now compiles once per CLI reporter** (a8a03c0)
The CLI switched from monomorphizing the install pipeline for multiple reporter types to using a single `CliReporter` path. That should shrink the binary and reduce compile duplication, with the change explicitly called out as about a 10% smaller executable on macOS arm64.

### **Trust-history checks cache better for large release histories** (e4c1ffc)
Registry trust scans now cache per-version metadata and reuse it across copied/filtered version maps, reducing repeated work on packages with long publication histories. The resolver keeps the same trust ranking behavior, but should be noticeably faster on cold and repeated scans.

### **Repeat-install filtering now respects Git redirect quirks and old versions** (9154a91)
The changed-project filter also picked up new tests and version detection logic around Git's diff output. This makes workspace filtering more robust across config settings and older Git installations.
