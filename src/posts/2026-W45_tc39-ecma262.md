### Host hooks for dynamic code get richer
**Dynamic code branding and compilation context expanded** — eval and Function now flow through a new `HostGetCodeForEval` hook, with `HostEnsureCanCompileStrings` taking clearer enum-based compilation types (`direct-eval`, `indirect-eval`, `function`). This gives hosts more precise control over non-string inputs and code translation/branding.

### Core abstract operations get simplified
**Typed array initialization unified** — the separate iterable and array-like initialization paths were merged into `InitializeTypedArrayFromElements`, simplifying typed array construction rules without changing behavior.

**Leap-year logic becomes reusable** — `InLeapYear` was refactored into boolean-returning `IsLeapYear`, with callers now doing the `YearFromTime` step themselves. The new shape is cleaner and better suited for reuse in future time-related work.

**Break and label evaluation no longer builds extra completion records** — breakable and labelled evaluation now return directly when a matching break is found, and completion-record guidance was tightened so `[[Target]]` is only meaningful for break/continue completions.

### Spec text and editorial clarifications
**DisposableStack.move() and other algorithms were clarified** — `{Async,}DisposableStack.prototype.move()` now uses `OrdinaryObjectCreate` directly, matching the non-writable/non-configurable prototype setup.

**Atomics.waitAsync return shape is spelled out** — the spec now explicitly describes the `{ async, value }` result object instead of treating it as a plain Promise return.

### Other misc changes
- Added more descriptive figure IDs/alt text and xrefs for object/prototype and generator diagrams.
- Corrected edition intro text for ES2018/ES2019 examples.
- Tightened environment record wording and several internal-method descriptions.
- Clarified `%TypedArray%.prototype.sort`, `PromiseResolve`, `decodeURI`, `bind`, `FinalizationRegistry.register`, `SharedArrayBuffer` growth, `Date.parse`, `IsLooselyEqual`, and related wording.
- Linked TC39’s AI policy from CONTRIBUTING.md.
