### **Workspace config can now be split across included files** (a1ce6a1)
pnpm-workspace.yaml gained `include`, letting the root manifest delegate settings to other YAML files or config dependencies with one owner per setting. This is a substantial config-system change that affects how settings are loaded and written across the CLI.

### **pnpr adds browser SSO login flow** (7d4b626)
`pnpr` now implements the npm web login endpoints so `npm login` and `pnpm login` can authenticate through an OIDC provider in the browser. It also adds the supporting session, rate-limit, and server routing pieces needed for the new flow.

### **Packument responses now support HTTP caching** (27004ec)
`pnpr` now emits `ETag`, `Vary: Accept`, and `Cache-Control` headers for packuments, and returns `304 Not Modified` on matching conditional requests. That reduces unnecessary payloads and makes registry responses cache-friendly.

### **Gist dependencies and gist repository URLs now resolve correctly** (9bb8f52)
The git resolver now recognizes `gist:<id>` and gist URLs as a first-class host, so install/add, `pkg fix`, and SBOM generation all handle them consistently. This fixes a real resolution gap and aligns pnpm more closely with npm's behavior.

### **pnpm self-update now respects pinned projects under Homebrew/Corepack** (74ad723)
When pnpm is externally managed, `self-update` now updates the project pin without trying to replace the global install first. That removes a long-standing blocker for pinned projects while preserving the existing refusal when no pin is present.

### **pnpm prune now honors trustLockfile** (629c083)
`pnpm prune` no longer hardcodes untrusted lockfile policy and now reads the configured `trustLockfile` setting like other commands. Trusted prunes also avoid an extra registry-metadata fetch in the skipped-resolution path.

### **Patch validation no longer flags copied/touched files as modified** (45bd62f)
Pre-run dependency checks now compare patch contents against the lockfile hash instead of treating file timestamp changes as modifications. This closes a false-positive bug that could repeatedly mark deps outdated even when patch content was unchanged.

### **Interrupted recursive runs now exit with the script's status** (01bf018)
A Ctrl+C during recursive or filtered `pnpm run` is no longer misreported as a first-failure task error. The run machinery now tracks interrupts more accurately so cancellation behaves like cancellation, not a task failure.

### **Deploy no longer rejects safe file: dependencies outside the lockfile dir** (34c3ca4)
`pnpm deploy` stopped blocking local `file:` dependencies that resolve outside the lockfile directory, matching install behavior. The previous check was only guarding reads, so removing it unblocks valid deployments.

### **`pnpm pack` and `pnpm publish` stop shipping common junk files** (91c6d76)
The packlist walker now applies npm-compatible default ignore patterns such as editor swap files, AppleDouble files, and build leftovers. This is a practical bug fix that prevents accidental tarball bloat and leaked artifacts.

### **`pnpm pkg fix` now normalizes repository fields** (e22d34b)
`pkg fix` now rewrites repository strings into the normalized object form and expands recognized hosted-git URLs, including gist URLs. This brings the command closer to npm's normalization behavior and improves manifest consistency.

### **`pnpm pkg fix` shares ill-typed field cleanup logic** (aa0e4b4)
The TypeScript CLI now reuses the same helper for dropping ill-typed manifest fields. This is a cleanup-only refactor with no behavior change.

### Other misc changes
- Maintenance tooling added for `pnpr` config checking, verification, export, storage migration, and htpasswd import (bc35481)
- OIDC auth internals were split into smaller modules in `pnpr` (33f531e)
- macOS link-thread pool behavior changed for `PNPM_MACOS_LINK_THREADS=0` (3f26021)
- `pnpm` now keeps import paths stable in the ESM Node_PATH loader fallback (dd95acd)
- Registry name mismatch validation was tightened in the npm resolver (7baeaaa)
- Minor CI/workflow and dependency updates, plus docs/readme/example fixes (902b4a8, 7162c6f, 3876e3f)
