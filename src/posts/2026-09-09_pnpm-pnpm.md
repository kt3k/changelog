### **Critical symlink-extraction hardening for tarballs and runtime downloads** (8cd45fd)
pnpm now unpacks downloaded runtime archives into a random store directory and blocks extraction if an existing symlink would redirect writes outside the target. The bundled `adm-zip` patch closes GHSA-vwc7-r8mq-g2x9 for the vendored tarball path.

### **`updateConfig` now sees the resolved config, not one file's settings** (bc7dc8b)
The `updateConfig` pnpmfile hook now receives the resolved config, so hooks can inspect values coming from `.npmrc`, CLI flags, and defaults instead of only `pnpm-workspace.yaml`. That fixes scoped registry routing and other cases where the hook previously saw incomplete input.

### **`pnpm dedupe` now honors workspace selection and `--fail-if-no-match`** (def162f)
Dedupe now follows the same workspace/project selection logic as install, including separate lockfiles per project. That makes default dedupe cover all workspace projects and fixes filtered runs and no-match behavior.

### **Ctrl+C now waits for scripts to shut down** (a60dc90)
pnpm now forwards interruption to the child process and waits for it to exit instead of quitting first. This prevents script output from landing back on the shell prompt after an interrupt.

### **`ignoredOptionalDependencies` is applied during fresh resolution** (38d0051)
Optional deps listed in `ignoredOptionalDependencies` are now excluded even when pnpm resolves from scratch, not just when rewriting an existing lockfile. This fixes installs, adds, and dedupe so the lockfile and node_modules stay consistent.

### **Global bin management now fails closed on partial reads** (d3ab827)
Global add/update/remove no longer mutates bins or install directories if any installed package manifest in the target group is missing, malformed, or unreadable. That avoids orphaned or incorrectly removed global commands when enumeration is incomplete.

### **Node download mirrors can be set globally and via env** (734cd5b)
`nodeDownloadMirrors` is now a recognized config key, can be set in the global config file, and can be supplied through `PNPM_CONFIG_NODE_DOWNLOAD_MIRRORS` as a JSON object. That makes machine-wide Node mirror configuration possible.

### **Hashing lockfiles is cheaper in memory** (51fc229)
pnpm now sorts JSON objects in place before hashing lockfiles instead of rebuilding every map recursively. The digest stays stable, but verification of large lockfiles allocates less.

### Other misc changes
- Major install module refactors across pnpm/package-manager, deps-restorer, and related Rust internals
- Fresh-install and frozen-install pipeline refactors to satisfy the bindings cap
- Minor CLI/docs/style updates, including command reference wording and lint-related cleanup
- Network no-proxy matcher fix for leading-dot entries
- Global bin ownership cleanup hardening and related test coverage
- Misc CI/workflow, dependency, and test-only changes
