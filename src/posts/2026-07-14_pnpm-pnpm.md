### **Windows scoped symlinks now use native separators** (d52abd7)
A Windows-only filesystem bug could leave forward slashes inside `node_modules/@scope/name` symlink paths, causing `CreateSymbolicLinkW` to fail with `ERROR_DIRECTORY`. The fix rewrites paths to native separators before symlink calls, which should unblock installs for scoped dependencies on Windows.

### **self-update now records the resolved package-manager pin** (e0c790c)
`pnpm self-update <dist-tag>` was writing the tag used to invoke the command into `packageManagerDependencies`, even though the manifest pin was updated to the resolved version. That mismatch could make a later `--frozen-lockfile` install reject the lockfile as outdated; the fix makes the lockfile record the same specifier the manifest reads back.

### **Release and CI workflows were hardened** (a9b75f4, 338dda6)
Husky hooks are now disabled in the release-pr and update-lockfile workflows so CI doesn’t waste time running local git hooks during automated commit/push steps. Rust CI also now reruns when root package metadata changes, which should catch engine/package-manager-related changes sooner.

### **Other misc changes**
- Bumped pnpm/pacquet to 12.0.0-alpha.11 and regenerated lockfile metadata (30a59d0, e36df0a)
- Updated release changelogs and version constants for alpha.11 (e36df0a)
