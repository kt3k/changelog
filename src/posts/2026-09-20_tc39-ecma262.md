### **TypedArray setter return values clarified** (726ec8a)
The spec now treats `SetViewValue` as returning `unused` instead of `undefined`, and updates the various typed-array/DataView-style setters to `Perform` the write and then explicitly return `undefined`. This is an editorial consistency fix that aligns the abstract operation with how these methods are actually specified to behave.
