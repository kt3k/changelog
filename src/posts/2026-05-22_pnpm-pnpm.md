### **Pacquet closes the clean-install/perf gap** (976504f)
Pacquet’s fresh-resolution path was reworked to pipeline tarball fetching with dependency resolution and to reuse disk-loaded packuments in memory, cutting clean-install and full-resolution wall time substantially. The resolver now starts background downloads earlier and avoids repeated JSON parsing/spawn-blocking overhead, which is a meaningful speedup for install-heavy workflows.

### **Warm-cache resolution gets much faster** (5353fcb)
This commit closes most of the warm-cache resolution gap to pnpm by reshaping the install flow so prefetching can begin during resolution, rather than waiting for the tree walk to finish. It also threads shared tarball-cache state through CLI/install plumbing so the background fetches and later install pass can cooperate on the same in-memory cache.

### **Leaf packages now collapse to one dependency-tree node** (54ff453)
Packages with no deps, peers, optional deps, or peer metadata now reuse a single tree node across all parent occurrences instead of allocating a fresh node each time. That reduces the size of the dependency graph seen by peer resolution and downstream maps, which should improve both memory use and resolver throughput.

### **Cyclic peer suffixes are now deterministic** (3422cec)
A long-standing nondeterminism in `install`/`dedupe` was fixed when transitive peer dependencies reference each other and `auto-install-peers` is on. The lockfile should stop flipping between equivalent forms across runs, which matters for reproducibility and avoids noisy lockfile churn.

### Other misc changes
- Benchmark CI now runs the clean-install and full-resolution scenarios too.
- Broader clippy/lint rule updates and a few small style-driven refactors.
- Minor benchmark/workspace plumbing adjustments and test snapshot updates.
