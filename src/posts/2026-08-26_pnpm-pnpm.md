### **pnpr got a major crate split and hosted-digest support** (54957d7, 7237ade, 49ad901, 959be08, 195c697, 958a6aa, a5e4791, ceed82f)
The pnpr Rust codebase was aggressively modularized into smaller crates and modules, reducing the monolith into clearer layers and extracting config, auth, routing, storage, OSV, and error handling boundaries. In the same vein, hosted registries now support digest-addressed original artifacts, with journaled revision references and new conflict/limit errors to make that lookup durable and safe.

### **pnpm install/update/deploy/fetch picked up user-visible fixes** (45b66df, f656f02, 327e6af, 0ec67d0, 6b521cd, 4e88dd1)
Deploy now correctly injects transitive workspace dependencies, verifier output stays off stdout, package-manager switching follows the lockfile’s resolved pnpm version, and `pnpm update --patches` can refresh registry revisions through pnpr. pnpr resolution also started preserving patches and package extensions, while `pnpm fetch` now links virtual-store bins so lifecycle scripts can resolve sibling binaries.

### Other misc changes
- Dependency, Node.js, pnpm, and GitHub Actions updates (3 commits)
- pnpr/jest config path fix
- pnpm v12 stable release prep
