### **Service account, self-serve deletion, and scope handoff** (0ab10d5)
Introduces a service account intended for future admin automation, along with admin-panel and self-service user deletion. The deletion flow now transfers scopes to the service account when the deleted user was the sole member, preventing orphaned ownership and keeping scopes accessible.

### Other misc changes
- SQL query updates supporting user deletion and ticket/creator reassignment.
- Schema/query cache refreshes for the API layer.
