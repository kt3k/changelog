### **Compact install summaries with post-check footer** (c1ce963)
Install output is now much terser: version changes render on one line, workspace project attribution is condensed, and deprecated packages, peer issues, and the supply-chain verdict are grouped at the end. This makes the final install status easier to scan without losing the important warnings.

### **Frozen installs now accept equivalent local override paths** (c004018)
Frozen lockfile verification now recognizes when a workspace override and lockfile point to the same local dependency through different but equivalent relative paths. That avoids false rejections on offline frozen installs while still rejecting paths that only look equivalent but resolve differently.

### **`pnpm approve` can approve a Git repo across updates** (dcb26c9)
The interactive approval flow now supports repository-scoped Git dependency approvals, so one Git package can be approved across future updates rather than only for a specific commit. The picker and decision storage were updated to track repository identity, which matters for recurring Git dependency workflows.

### **Dependency edits preserve declared runtime policies** (78a8a1a)
Saving dependency changes no longer strips runtime policy declarations from `package.json` when `runtimeOnFail` is in play. That prevents install/update/remove flows from silently rewriting runtime settings, including cases where the runtime entry is explicitly removed.

### **Unicode line separators are preserved in workspace YAML** (1331656)
`pnpm config set` now round-trips values containing U+2028/U+2029 and U+0085 instead of letting the YAML emitter turn them into accidental line breaks. The writer falls back to JSON-style escaping where needed so values survive reads unchanged.

### **Empty directory env vars now behave as unset** (1ce2e4b)
Empty `XDG_*` and `PNPM_HOME`-style directory environment variables now fall back to defaults instead of creating config/cache/home directories under the current working directory. This closes a nasty footgun that could make pnpm write global state into a local `pnpm/` folder.

### **pnpr avoids Turso/libSQL idle-connection races** (f4bfbf0)
pnpr now closes pooled libSQL connections sooner so it doesn’t hand out a connection right as Turso is likely to drop it. That reduces intermittent `ERR_PNPR_LIBSQL` 500s on writes after idle periods.

### **Workspace manifest writes now match file quote style** (a6d032b)
Quoted values added to `pnpm-workspace.yaml` now follow the file’s existing quote style instead of always using single quotes. This keeps generated workspace manifests consistent when pnpm appends or rewrites entries.

### Other misc changes
- Catalog peers for local file dependencies fixed (d4ddd10)
- Quote-style regressions and runtime/YAML/path edge-case tests updated
- CLI/reporter internal refactors to support the install summary and approval changes
- pnpr test harness and connection-pool test updates
