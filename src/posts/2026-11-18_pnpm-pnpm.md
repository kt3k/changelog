### **RPM packaging lands for standalone pnpm releases** (8011e3e)
pnpm now attaches an RPM of the standalone Linux x64 CLI to releases and publishes a dnf repository for RHEL 8+ systems. This makes `dnf install pnpm` work on hosts that can't reach pnpm.io, expanding install options for enterprise Linux users.

### **Security: patch picomatch against repeated-wildcard ReDoS** (f7a1f7d)
The bundled picomatch dependency is patched for GHSA-fc5q-39xc-vjpf, closing a ReDoS where repeated wildcard globs could hang on long paths. This is a direct security fix for path-matching inputs.

### **Refactor: remove platform variants from package publishing** (6a05397)
pnpm and pnpr no longer support platform variants for a package version; each version now has a single archive again. This is a breaking change that removes `publishConfig.variants`, variant-related publish flags, and variant archive serving, simplifying the release model at the cost of compatibility.

### **Lockfile and install options gain v13 format control** (b619cf4)
The N-API install bindings now accept `lockfileFormat`, letting embedders choose between v9 and experimental v13 lockfiles explicitly. The same change also fixes a case where installs that updated an existing v9 lockfile without resolving could incorrectly keep the old format.

### **Frozen lockfile checks now validate plain-range workspace children** (33c3cb6)
Frozen-lockfile validation now handles directory dependencies whose children resolve into workspace projects through plain or npm-aliased ranges. That closes a correctness gap around linked vs injected workspace resolution and compares injection metadata against the recorded lockfile reference.

### **pnpm honors Ctrl+C before launching the native binary** (bc99b8f)
The Unix launcher now waits long enough to catch early SIGINT before spawning the native binary, so Ctrl+C is no longer dropped in the handoff path. It also improves launch error handling by detecting shell-less environments and non-executable binaries more reliably.

### **pnpr now returns freed memory to the OS** (c13b416)
pnpr switches to mimalloc on supported desktop/server targets and explicitly purges freed memory immediately at startup. This reduces resident memory growth under concurrent packument reads and helps idle servers release memory instead of staying near peak usage.

### **`pnpm audit` now handles `time.unpublished: null`** (db32786)
Audit now parses packument timestamps as JSON values, preserving valid published timestamps even when the registry includes a null or object `unpublished` marker. That avoids silently skipping patched versions when registry metadata contains mixed `time` entries.

### **Git dependencies are reused more aggressively in lockfile-only installs** (8a30f5e)
Lockfile-only resolution now reuses recorded Git package and dependency snapshots when the repository hasn't changed. This reduces unnecessary re-resolution work while keeping peer and exotic subdependency checks intact.

### **Peer checks stop flagging injected catalog peers incorrectly** (d594d85)
`pnpm peers check` and install warnings now resolve `catalog:` peer ranges for injected workspace packages through workspace catalogs. That fixes false unmet-peer reports when the installed version actually matches the catalog entry.

### **Other misc changes**
- `pnpm dedupe` skips metadata refreshes when the result won't be recorded (3002908)
- `pnpm ci` passes the correct current lockfile to preResolution with an external virtual store (dce7771)
