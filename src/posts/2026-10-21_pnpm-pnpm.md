### **Install bin linking is much faster** (e2a11f5)
pnpm now precalculates package bin targets and shebang runtimes during tar extraction and uses that metadata to link `.bin` shims without rereading `package.json` or walking package directories. This cuts work out of install-time bin resolution and should noticeably speed up large installs.

### **`pnpm dedupe` refreshes stale registry metadata** (f0982d4)
Dedupe now revalidates cached packument metadata while re-resolving locked versions, which fixes cases where deprecation or other registry-side metadata changes were missed. That makes `dedupe` behave consistently even when the local metadata cache is stale.

### **`pnpm pack` / `publish` keep `pnpm.config`** (7ef0e9d)
Packed and published manifests now preserve the `pnpm.config` pointer while still stripping the rest of the internal `pnpm` field. pnpm also always includes the referenced config file in the tarball, so config dependencies keep working after publish.

### **Deduping check ignores registry deprecation notices** (cbe5acc)
`dedupe --check` no longer fails just because the registry added a deprecation notice after the lockfile was written. This removes cache-freshness-dependent false positives where the same commit could pass locally but fail in CI.

### **Core-dumping child signals no longer double-core pnpm** (e2a11f5)
When a child process dies from a signal like `SIGABRT` or `SIGSEGV`, pnpm now re-raises the signal without triggering an extra core dump from pnpm itself. That keeps Unix signal behavior correct without producing duplicate crash artifacts.

### **Tarball path rejections fail fast** (3ce74f1)
Rejected archive entry paths are now treated as permanent errors, so pnpm stops retrying immediately instead of sleeping through the retry budget. The tarball extractor also carries the rejection reason explicitly, which improves security handling for path traversal-style archives.

### Other misc changes
- Major resolver/refactor work across install freshness, dependency graphs, and `why` output.
- Fixed package import behavior for built packages and patched hoisted packages.
- Added interactive update prompt highlighting improvements.
- Several workspace, CI, release, and dependency maintenance changes.
