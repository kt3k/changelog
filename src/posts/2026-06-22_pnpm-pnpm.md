**pnpr now enforces auth, policy, and tarball integrity more strictly** (4c4acb6, 85d9e77, cdc897f, bb1872d, 88add09, f742b04, 1c04a00, 5dc8593, faf31ef)
The registry now checks bearer-token restrictions and resolver requests before work starts, enforces separate unpublish authorization, makes self-registration opt-in by default, and rejects unsafe htpasswd usernames. It also tightens tarball handling and OSV filtering so pnpr fails closed on integrity and storage issues instead of serving or mutating data it should not.

**pnpr can now expose registry and resolver surfaces independently** (bed6c59, 4d3fe4b)
The server gained feature toggles for the registry and resolver surfaces, with CLI flags to disable either side and validation that at least one remains enabled. Resolver endpoints were also moved under the reserved `/-/pnpr` namespace, reducing route conflicts with package names.

**pacquet ports build-policy commands and the runtime command** (7e1be2f, 0ec878d)
The Rust CLI now supports `approve-builds`, `ignored-builds`, `rebuild`, and the `runtime`/`rt` command. These changes wire the commands into the existing install/add pipeline and make the Rust CLI behave much closer to pnpm for build approval and runtime manifest editing.

**Pacquet cache and store inspection commands were added** (be60cd6, d1635db, e72b482)
`cache`, `cat-index`, and `find-hash` were implemented in the Rust CLI, covering cache listing/view/delete, store index inspection, and digest lookup. These fill out more of the pnpm command surface in pacquet.

**pnpm now computes missing tarball integrity on download** (bae694f)
When a registry omits tarball integrity metadata, installs now compute it from the downloaded bytes and persist it into the lockfile. That prevents lockfiles from being written in a state that would fail on the next install.

### Other misc changes
- Benchmark auth path switched from Basic auth to bearer tokens for pnpr load tests.
- Lockfile/version updates.
- Small runtime-selector normalization and Windows dlx cleanup fixes.
