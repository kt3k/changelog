### **pnpr adds admin APIs for users, teams, and rules** (1464027, 398b450, 1066dce, 3b5af3f, 0925ab2, 23edc7d, 0158dba, 3b4c1f7)
Hosted registries got a big management upgrade: admins can now create and manage users, edit teams, change package rules, and grant access through admin endpoints instead of config deploys. The related auth changes also tighten token ownership, add OIDC group-to-team mappings, and make rule updates conditional with `If-Match` so concurrent edits don’t silently overwrite each other.

### **pnpm can install and run Rust toolchains** (19818f1, fad744e, 78810c4)
`rust` is now treated as a first-class toolchain target in both project and global flows, with `pnpm add rust`, `pnpm add -g rust`, and Rust-aware shims for `cargo`, `rustc`, and related tools. pnpm reads `rust-toolchain.toml`, installs the requested channel, and routes commands through the pinned toolchain when a project has one.

### **pack, patching, and Windows import handling got major fixes** (6940e6d, 0facff5, 45e7917, c1cfe3d)
`pnpm pack`/`publish` now match npm-style `.npmignore` negations and extglobs, patch application now preserves Unix file modes and accepts CRLF patch headers, and Windows package imports handle invalid filenames more safely. The Windows work also warns on renamed paths, retries transient junction/delete-pending races, and avoids bad retry behavior in hoist/import paths.

### **Performance and rebuild behavior improved** (c267bc1, b6a49cd, a78bf0b, faa2606, a3f0526, f5ad844)
Several rebuild and storage paths were optimized, including lockfile verification, manifest serialization, and the rebuild selection logic that had been probing too many packages. pnpm also stopped deleting and reimporting whole `node_modules` trees on some drifted settings, capped Rayon thread-pool sizing in the Node addon, and now vacuums the store index after prune.

### **Registry resolution and CLI behavior were standardized** (7db12c4, d3011fd, 7032f08, 9950d66, 7cb574b, ad4d315, 643ebac, bb4cb62, f89b6b8, 49f4517)
Registry override handling was unified across many commands, `whoami` gained a `--registry` option, and several package/inspection commands now resolve endpoints and auth headers consistently. There were also correctness fixes for outdated/version lookups, registry URL normalization, and repo lookup parallelization.
